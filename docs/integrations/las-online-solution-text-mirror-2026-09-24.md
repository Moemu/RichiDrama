## 一、LAS 算子是什么

LAS 算子是 AI 数据湖服务（LAS）面向企业多模态数据处理场景的算子服务矩阵，覆盖文本、文档、图像、音频、视频等 150+ 个算子。在豆包大模型基座能力上，通过工程优化、效果增强、链路封装提供可插拔的全栈多模态处理能力，可被企业编排成 Pipeline 或直接调用 API。

### 1.1 一句话理解

LAS 算子 = 基座大模型能力 + 工程增强 + 效果确定性 + 一站式调用。算子把「大模型 + 处理流程 + 工程化手段」封装成接口，目标是直接输出业务可用的结果。

### 1.2 为什么用算子

| 问题 | 直接调大模型 | 用 LAS 算子 |
| --- | --- | --- |
| 输入时长与抽帧受限 | 长视频有输入时长和抽帧限制 | 内置转码、切分、帧率自定义等处理，支持小时级视频、10GB 级输入 |
| 输出不是业务可用的格式 | 输出通用描述 | 输出短剧剧本、结构化资产、成片素材等业务形态 |
| 单一模型能力不够 | 复杂任务需自建工作流 | 封装多模型、工作流与工程化处理 |
| 效果一致性难保证 | 角色跨集音色或风格难保持 | 内置角色理解、风格统一流程 |

视频、音频类输入按元/分钟计费；文本推理类按元/百万 Token 计费。具体以各算子官网说明为准。

## 二、我们服务谁：短剧与广告客户画像

从剧本理解与改编，到素材生产、画质提升和多语言出海，能力可按单算子接入，也可组合成「内容理解—创作改编—成片加工—全球发行」链路。

| 客户类型 | 痛点 | 首单建议 |
| --- | --- | --- |
| 短剧出海平台／内容方 | 存量成片需要快速铺多语种、多市场 | 字幕擦除 + 视频翻译 |
| 发行方（采版权 + 翻译投流） | 大批量处理，人工译制成本高、周期长 | 视频翻译 + 字幕擦除批量处理 |
| 投流／买量团队、MCN | 素材铺量压力、剪辑周期、查重限流 | 爆款素材剪辑 + 视频超分 |
| 制作公司／精品化团队 | 剧本产能不足、海外原生内容成本高 | 剧本还原 → 解析 → 裂变／修改 → 转分镜 |

原文列举的典型客户包括麦芽、九州、山海、漫森、稻谷、昆仑万维、百川文化、点众、柠萌等。广告客户的核心诉求是高频测试、批量扩量、降低单条素材成本和提升 ROI。

## 三、短剧全链路解决方案

| 业务阶段 | 算子链路 | 目标 |
| --- | --- | --- |
| 内容理解 | 剧本还原 → 剧本解析 | 从成片得到剧本与角色、场景、情节数据 |
| 批量改编 | 剧本解析 → 修改／裂变 → 剧本转分镜 | 从结构化剧本推进镜头和资产准备 |
| 成片加工 | 视频拆镜 → 参考素材配置 → 视频编辑增强版 2.0 → 版本选择与下载 | 替换人物、主体与背景，或做风格转绘 |
| 投流扩量 | 爆款素材剪辑；短剧·影视解说智作 | 批量生成投流素材或解说素材 |
| 多语言出海 | 字幕擦除（可选）→ 视频翻译 | 生成干净母版、配音、字幕和目标语言成片 |

原文称爆款剪辑可对一部 100 分钟短剧生成 50 条 2 分钟投流视频；多语言链路中，100 分钟短剧制作一个语种的示例成本约 190 元。这些是方案示例，不是本项目报价。

## 四、算子能力详解

### 4.1 内容理解

#### 4.1.1 剧本还原

输入短剧视频，识别角色、对白、场景与剧情线，输出带时间信息的结构化剧本，可用于二创、翻译校对和内容复盘。输出包括角色表、剧情梗概、对白及分镜级剧本。原文价格为火山引擎 ¥1.50／输入分钟，BytePlus US$0.21／输入分钟。

原文展示的示例文件包括 `ep_001.md`、`ep_001_characters.json`、`ep_001_scenes.json`、`ep_001_props.json`；附件内容未包含在本地镜像。[BytePlus 文档](https://docs.byteplus.com/en/docs/Byteplus_LAS/Short_drama_script_generation)

#### 4.1.2 剧本解析

把非结构化剧本文本转为角色、场景、对白、动作和情节等结构化数据，供裂变、修改、分镜和资产生产使用。原文价格为火山引擎输入 ¥15／百万 Tokens、输出 ¥75／百万 Tokens；BytePlus 输入 US$1.25／百万 Tokens、输出 US$6.25／百万 Tokens。[BytePlus 文档](https://docs.byteplus.com/en/docs/Byteplus_LAS/Short_drama_script_parsing)

### 4.2 批量改编

#### 4.2.1 剧本裂变

保留原故事的核心冲突和人物关系，按题材、节奏或目标市场生成多个剧本版本。输入为原剧本与裂变要求；输出为多个裂变剧本版本。原文展示美国纯英文版、美国混合语言版和泰国地域版等示例。火山引擎输入 ¥15／百万 Tokens、输出 ¥75／百万 Tokens；BytePlus 输入 US$1.25／百万 Tokens、输出 US$7.50／百万 Tokens。大段中英文示例剧本未复制到本文件。[BytePlus 文档](https://docs.byteplus.com/en/docs/Byteplus_LAS/Short_drama_script_fission)

#### 4.2.2 剧本修改

用自然语言指令控制人设、冲突、节奏、题材和目标市场的改稿目标与范围。输入为原剧本和修改指令；输出为修改后的完整剧本。原文示例强调人物、组织、地点和道具专有名词统一替换，普通术语不误替换，人物表、场景表、道具表和各集剧本保持一致。火山引擎输入 ¥15／百万 Tokens、输出 ¥75／百万 Tokens；BytePlus 输入 US$1.25／百万 Tokens、输出 US$6.25／百万 Tokens。[BytePlus 文档](https://docs.byteplus.com/en/docs/Byteplus_LAS/Short_drama_script_revision)

#### 4.2.3 剧本转分镜

从剧本与角色、场景资产生成结构化分镜包，包含镜头、人物、动作、对白和资产描述。原文价格为基础调用 1 元／次，文本理解 0.1 元／千字。示例文件包括 `shot_registry.json`、`characters_registry.json`、`prop_registry.json`、`scene_registry.json`；附件内容未包含在本地镜像。[LAS Online operators](https://docs.byteplus.com/en/docs/Byteplus_LAS/Online_operators)

### 4.3 成片加工

#### 4.3.1 视频编辑增强版 2.0

原文标注正式上线时间为 9 月 9 日。输入为原视频、自然语言编辑指令、可选参考图及素材映射关系。能力包括通用／局部画面编辑、人物替换、主体与背景替换、风格转绘及直通生成；目标是尽量保持原镜头结构、动作、节奏和时间线。可按片段、Pipeline 或完整成片下载。原文声称有效出片率约由 25% 提升至 90%。

原文价格只写明「换脸最终价＝基础价＋0.010；其余四种 Mode 最终价＝基础价＋0.025」，未在该表解释基础价和单位。[接入参考](https://bytedance.larkoffice.com/docx/LDsddCOtIo7nJSxeD6Tl52Kzgnd)

### 4.4 投流扩量

#### 4.4.1 爆款素材剪辑

上传一部短剧的一集或多集视频，自动寻找高光片段，一次生成多条差异化投流素材。结合短剧三要素、精彩度识别和剪辑策略，支持顺剪、跳剪、精彩前置。原文称最多输入 100 集；输出多条短视频，以及分镜分析、镜头评级、钩子分、素材片段、时间线和还原剧本等结构化 JSON。

可配置目标素材数量、单条时长、剪辑策略、精彩前置、剧名、提示语、角标和后贴。原文还描述非正片清洗、S/A/B/C 精彩度评级、开头与结尾钩子分、多套包装模板。标杆客户列为新美、蜜糖、秒针，并称秒针客户日均产出 2000+ 条素材、投流 ROI 提升 10 倍；这些数字未由本项目核验。

| 计费项 | 原文价格 |
| --- | --- |
| 火山引擎 LAS 输入视频分析 | ¥1.50／分钟 |
| 火山引擎 LAS 剪辑合成输出 | ¥0.06／分钟 |
| BytePlus 输入分析 | US$0.25／分钟 |
| BytePlus 输出成片 | US$0.01／分钟 |

原文成本示例：30 分钟输入和 30 分钟输出，LAS 约 ¥46.80。[BytePlus 文档](https://docs.byteplus.com/en/docs/Byteplus_LAS/Viral_content_editing)

#### 4.4.2 短剧·影视解说智作

以多集短剧或单部电影为输入，建立剧情事件索引，按 short、mid、long 三类时长规划跳剪解说视频。算子完成画面剪辑、解说稿、TTS 配音、字幕、混音渲染和结果上传。支持中英文、精彩前置、高光留白、语速控制、可选参考音频音色克隆，以及字幕底框和位置控制；一次任务输出一条解说视频。

原文价格：输入总时长不超过 60 分钟时按 ¥0.20／输入分钟，超过 60 分钟按 ¥0.30／输入分钟；输出按实际成片时长 ¥1.20／分钟。30 分钟输入、3 分钟输出的示例费用为 ¥9.60。[火山引擎文档](https://docs.volcengine.com/docs/6492/2671548?lang=zh)

### 4.5 多语言出海

#### 4.5.1 视频翻译

上传有音轨的原视频，指定源语言、目标语言及翻译模式，一次异步任务生成译后配音、字幕和 MP4 成片；可选面容翻译以同步人物口型。原文称基础链路复刻原说话人的音色和情绪，并使译后语音时长贴近原片。

输入可为公网 URL 或 TOS 地址。原文限制为文件最大 10 GB、时长 10 秒至 4 小时；面容翻译要求单条视频小于 10 分钟、帧率不高于 30 fps。源语言需显式指定；该方案处理离线视频，不支持直播同传。

| 计费项 | 原文价格 |
| --- | --- |
| 火山引擎 LAS 视频翻译 | ¥1.50／输入分钟／语种 |
| 火山引擎 LAS 面容翻译（可选） | ¥4.00／分钟／语种 |
| 两项整段叠加 | 约 ¥5.50／分钟／语种 |
| BytePlus 视频翻译 | US$0.32／分钟 |

原文列举百川文化案例的 31 种语种接入、单日处理峰值 3.2 万分钟和 50 部剧同期上线等数据；这些数据未由本项目核验。[视频翻译官方文档](https://docs.byteplus.com/en/docs/Byteplus_LAS/Video_Translation_operator)

#### 4.5.2 字幕擦除

识别并擦除硬字幕，对擦除区域做内容修复，产出干净母版，可接视频翻译。输入为带硬字幕的视频及可选字幕区域；输出为去字幕且完成修复的视频。原文价格：标准版 ¥0.40／输出分钟，精细版 ¥1.00／输出分钟。[视频修复文档](https://docs.byteplus.com/en/docs/Byteplus_LAS/Video_restoration)
