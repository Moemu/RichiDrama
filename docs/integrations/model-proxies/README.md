# 模型中转平台配置示例

此目录保存第三方模型平台的导入示例和界面截图。

## 使用方法

1. 在管理界面打开“AI 配置”。
2. 选择一个 `examples/` 中的 JSON 示例。
3. 导入配置。
4. 将示例地址、模型名和所有密钥字段改为自己的值。
5. 保存后执行不产生费用的连接检查。

## 目录

- `examples/`：第三方平台 JSON 示例。
- `images/`：平台界面和字段位置截图。
- [ComfyUI 集成](../comfyui/README.md)：本地 ComfyUI 代理说明。

## 安全要求

- 示例文件不得包含真实 API Key。
- 不要提交 `.env`、访问令牌或供应商密钥。
- 不要直接使用示例中的服务地址和模型名。
- 真实生成调用必须通过项目 `/api/v1/...` 路由。

第三方平台名称只用于说明配置格式，不表示项目提供背书。
