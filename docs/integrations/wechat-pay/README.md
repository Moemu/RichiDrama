# 微信支付配置安全说明

项目已经实现微信 API v3 Native 支付。

完整接入流程见 [支付宝与微信 ToC 充值](../payments/README.md)。

## 常见配置项

- 商户号 `mchid`
- 应用 ID `AppID`
- API v3 密钥
- 商户 API 证书序列号
- 商户私钥文件
- 回调令牌或回调验签配置

## 安全要求

- 不要在截图、Word、Markdown 或日志中保存真实值。
- 不要把商户私钥、证书包或密钥文件提交到 Git。
- 使用环境变量或专用密钥管理服务。
- 为开发、测试和生产环境使用不同凭据。
- 如果凭据曾进入 Git 历史，立即轮换凭据。

原 Word 文件包含凭据画面，因此不再保留在当前代码树中。
