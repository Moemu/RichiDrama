# 协作编辑交付回归

## 行为

结构保存使用读取或开始编辑时的字段值。WebSocket 推送和后续读取不会替换已打开表单的编辑基线。画布拖动、对齐和工作流保存固定当前布局；失败时保留修改，可明确放弃后刷新。新建节点读取创建结果后保存指定位置。

角色、场景和道具编辑弹窗使用本地文字草稿。取消不写入文字，保存时检查打开表单时的字段值。覆盖项目详情、制作页和仍有数据的历史项目库入口。图片上传、生成等独立操作仍立即执行，不属于文字取消范围。

协作文字未确认或有待恢复草稿时，页面跳转提示用户留在页面或明确放弃。留在页面保留原文档，重连后补存。关闭或刷新浏览器使用原生未保存提示；没有承诺关闭浏览器后恢复未保存草稿。

## 消费者与兼容范围

检索覆盖 `frontweb/src`、`backend-node/src`、`backend-node/test` 中的项目版本、协作会话、文字绑定、关联数组和画布保存消费者。

- 请求封装和快照：详情、制作页、画布、分镜角色/场景/道具关联及项目模式的素材关联。
- 编辑入口：详情页三个制作资源弹窗；制作页三个资源弹窗与三个历史项目库弹窗。
- 会话生命周期：路由守卫、浏览器卸载提示、协作连接、未确认文字、恢复草稿和重新连接。
- 后端：继续使用现有鉴权、所有权、操作去重和版本冲突校验；没有新增业务路由、迁移或供应商调用。

版本保护作用于已启用协作的项目，包括新建项目和负责人此前明确启用的项目。未启用协作的历史项目保持旧接口语义。取消弹窗的文字草稿行为适用于所有使用这些弹窗的记录。历史任务、媒体、账本和数据库内容均不迁移、不清理、不重算。

## 验证

- 前端自动化覆盖：旧读取版本与新 WebSocket 版本分离；表单版本不受后续 HTTP 读取影响；断线草稿取消离页、重连确认、恢复草稿和卸载提示；新建节点位置与创建后的版本。
- HTTP 集成覆盖：另一位成员先保存布局，旧版本返回 409，刷新后保存成功；后端重启后布局仍正确，历史私有项目仍可读。
- 内置浏览器使用独立临时 SQLite 数据库，禁止生成路由，不配置供应商。详情、制作页和画布分别检查 1280×720、1440×900、1920×1080；资源弹窗另检查 390px 窄屏和滚动。
- 真实交互确认取消不写入、保存生效、冲突保留表单、画布冲突恢复、断线离页提示及重启后的自动补存。

后端 435 项、前端 160 项测试通过，最终 production build 成功。既有 [负载报告](collaboration-load-test.md) 和 [20 人故障恢复报告](collaboration-resilience-test.md) 记录此前版本的服务端测试，不能替代这里的页面行为回归。

## 单人连续编辑回归

制作页读取生成参数时，清理首镜覆盖值的 SQL 以前会反复写入已经为 NULL 的字段，触发项目版本增加。现在只清理非 NULL 的覆盖值，连续读取不再制造版本变化。已有参数含义、首镜继承规则和历史记录保持原行为，没有迁移或批量改写。

HTTP 编辑不再依赖 WebSocket 已连接。HTTP 鉴权、项目权限、操作去重和版本校验仍由后端执行；实时文字仍保留原来的断线补存与离页保护。

资源和分镜写入携带本次修改字段的原值，由后端在同一事务中核对并保存，不再先 GET 项目再提交全局版本。确认成功的响应只推进本次修改字段的编辑基线。未变化的素材用途和提示词文档不重复写入。

补充消费者检查覆盖生成参数服务、读写路由、导入导出、分镜复制、制作页和项目分镜编辑器。自动化验证连续读取版本不变、自身文字更新后保存其他字段、连续调整生成参数、同字段冲突拒绝，以及重启后保留最后结果。内置浏览器在三档桌面尺寸下交替修改提示词、音频方式和时长（15→10→12），刷新后内容与参数一致；全部使用隔离数据，没有真实生成或费用。

## 分镜切换提示词隔离

原来的分镜监听使用 Vue 默认调度，提示词监听却同步写入。加载下一镜的提示词时，旧协作绑定还未解除，导致内容写入上一镜。现在同步解除旧绑定，待当前分镜加载完成后绑定对应文档；过期响应和过期错误不再影响当前编辑器。同一镜重新加载列表快照时也暂停绑定，避免将读取行为当作编辑。

提示词编辑器按分镜 ID 重建，隔离输入法、光标和素材选择状态。协作文档加载完成前暂时只读，避免新输入被初次读取覆盖。普通非协作编辑保留原行为；修复适用于所有已启用协作的项目，不迁移、重写或自动恢复历史提示词。

消费者检索覆盖 `useProjectTextModel`（制作页唯一调用方）、共享 `bindProjectText` 与表单指令、提示词编辑器、自动保存、提示词文档读写、导入导出和后端协作文本持久化。共享底层绑定与后端 API 没有变更。

新增真实 Vue/Yjs 回归先在原代码上复现跨镜写入，再验证切换不产生文本更新、延迟响应、缓存回切、同镜重载及独立编辑。前端 161 项测试和 production build 通过。隔离浏览器实测立即切换、反复回切、刷新，以及 1280×720、1440×900、1920×1080 和 390px 窄屏。HTTP 在后端重启前后确认两镜文本及提示词文档各自保留；既有项目资料和画布仍可读取。没有真实生成或费用。

## 独立操作与字段事务（2026-09-11）

旧请求拦截器给新建镜头、素材认证等独立操作附加整个项目的版本。提示词自动保存即可使版本过期。先 GET 再保存仍有竞争窗口，也未覆盖这些命令，因此移除此预读方案。

新建、导入和认证命令保留鉴权、项目权限和请求去重，不依赖无关项目版本。实体编辑、素材声明、画布、梗概、进度、分集编辑、分镜排序和生成参数使用可选的 `_project_edit` 字段条件。后端将核对、同步业务保存和去重结果写入放入同一 SQLite 事务。真正的字段或排序冲突返回 409，不自动覆盖或重新提交。生成参数仍保护本集参数和继承顺序；尚未转换的批量替换接口保留旧版本保护。

后端 HTTP 集成测试使用前端 Axios 和实际拦截器，因此运行前需在两个目录安装依赖。CI 后端任务包含这两个安装步骤。

制作页固定当前分镜的编辑基线，成功后只推进本次保存字段。素材声明单独提交，提交中禁止重复切换；后续认证失败保留已保存声明并明确提示。分镜详情、项目详情和分集列表统一输出 18 个持久化输入字段，避免缺失字段造成假冲突或刷新丢失。

消费者检索覆盖请求封装、认证重试、会话能力声明、详情/列表/历史库、画布与资源弹窗、分镜创建/复制/排序、素材声明/认证、生成参数与继承、提示词自动保存、操作去重、权限、刷新和重启。没有改变供应商适配、计费或媒体路径。

新协议只在服务端声明支持且项目已启用协作时使用。旧客户端和旧服务端保留原接口与版本头语义；未启用协作的历史项目明确排除。没有迁移、删除、重算或批量改写历史项目、任务、媒体及账本。

最终验证：后端 436 项、前端 165 项测试通过，production build 成功。新增集成测试将真实前端请求拦截器接入隔离 HTTP 服务，验证连续无关更新后创建/声明/认证/排序/参数保存、重复请求和重启去重、同字段冲突、布局冲突、只读权限、三个分镜读取接口一致及历史项目读取。浏览器在三档桌面尺寸检查制作页和画布，实际连续新建、编辑回切、声明切换、参数保存、认证失败及重启恢复，并检查 390px 窄屏操作。没有真实供应商调用或生产数据操作。

## 视频任务刷新后的预览（2026-09-11）

同一镜头已有成片且正在生成新版本时，刷新默认跟随进行中的任务。生成、认证等待、超分、插帧和保存阶段显示任务状态，不使用上一版成片或中间文件填充播放器。用户仍可明确点击历史版本预览，采用关系保持不变。页面跟随的任务进入终态后，继续显示该任务的结果或错误。

Omni 任务 ID 与视频记录 ID 分开保留，轮询中的嵌套视频 ID 不再覆盖任务 ID。消费者检查覆盖项目制作页和独立创作共用的预览、历史选择、任务列表/详情、轮询、下载/提帧入口及列表媒体恢复；画布和视频合成仍使用已有采用规则。后端、API、计费和任务状态均未修改，不迁移历史记录或媒体路径。

前端 170 项测试和 production build 通过。新增回归覆盖全部进行中状态、旧版手动预览、完成/失败后不回退、任务与视频 ID 不同和旧成片读取。隔离浏览器使用持久化任务及本地蓝色旧片、绿色新片，验证三档桌面尺寸、刷新、后端重启、手动历史预览和轮询完成后的新片显示；没有调用供应商。

## PR 审查回归（2026-09-11）

应用文本建议与协作正文更新共用持久化逻辑，同时同步全能提示词文档，保留引用。只保存引用时读取数据库原文，不再写入空正文。会话编号隔离旧 WebSocket、HTTP 响应和保存回调；指令也会丢弃禁用、切换目标及卸载后的绑定。

同步命令的业务写入和操作响应在同一事务提交，包括已有字段编辑及已核对的创建、复制、加入素材、应用建议、成员更新和图片/视频任务入队。生成处理仍在事务提交后的后台执行。进程在提交前退出时回滚，提交后同一操作 ID 返回原响应。

无法确认结果的异步命令不自动重放。新操作保存恢复版本和 15 分钟响应确认期限；连接关闭、流式响应结束或期限到达后，同一 ID 返回 `OPERATION_UNCONFIRMED`，提供项目生成记录查询地址。超时只改变提示，不解除去重；迟到的最终响应仍可保存。没有恢复标记的历史操作记录明确排除，保持原响应，不推断其结果或重新提交。

素材复制在写事务内查重。素材列表按项目一次读取分镜、制作资源和显式链接，保留原有用途及来源响应。只读素材库禁用卡片、标签、认证、裁切、拼接和归档，并在弹窗确认后重新检查权限；个人素材库保持独立。视频预览不再额外渲染图片元素，裁切区域移到播放器下方。

项目列表读取全部分页后再筛选和搜索。待对账任务优先于旧采用版本显示，但不加入自动轮询；手动历史预览及采用关系保持原规则。

消费者检查覆盖协作文本与建议路由、分镜详情/列表/提示词文档、生成输入和导入导出、请求拦截与操作去重、共享文本绑定及指令、素材列表/详情/删除保护、个人与项目素材库、任务历史选择和轮询。没有数据库迁移，不批量改写已有项目、媒体、任务或账本；文本修复仅在后续明确编辑时写入，复制保护仅作用于后续加入操作。

新增回归验证文本建议、引用保存和重启读取；实际进程终止后的事务回滚、响应回放和异步防重放；50 条素材与 1 条素材使用相同查询次数；跨会话迟到消息、快速回切和指令绑定竞态。前端 175 项测试和 production build 通过，后端全量 441 项通过。补齐旧测试库缺失字段，并将认证测试的固定延时改为限时等待实际状态。

内置浏览器在 1280×720、1440×900、1920×1080 和 390px 检查项目列表、素材库及分镜预览。57 个项目中，第 56 条参与项目和第 57 条旧项目均可筛选、搜索并滚动到末项。只读成员可预览；撤回权限后的重命名确认没有写入。两镜提示词独立编辑并在后端重启后保留，待对账任务刷新仍可见，手动刷新完成后播放新片。全部使用隔离数据库、本地测试媒体和空供应商配置，生成入口被阻止，没有真实供应商调用。
