# 项目协作实现与本地验收

本次范围为本地代码实现和验收，不含提交、推送或部署。

## 行为

- 项目保留负责人。负责人按准确用户名添加编辑成员或只读成员。
- 编辑成员共同编辑分集、分镜、资源、项目设置和画布布局。分集负责人只表示分工。
- 生成由发起人使用自己的模型权限、配置和余额。移除成员不会改变已提交任务的付款授权。
- 文本使用 Yjs 和 WebSocket。SQLite 在同一事务保存文档快照与业务文本，之后发送确认。
- 普通字段只发送改动值。结构操作带操作 ID 和项目版本；过期操作返回冲突。
- 操作记录在业务执行前持久化。已完成请求返回原结果；未确认请求不会自动重放生成。
- AI 回写遇到人工修改时，保留待应用内容。用户比较后决定是否应用。
- 画布布局和工作流分组共享；视口按当前用户和项目保存在本机。
- 个人素材首次保存为项目引用时，复制本地媒体、缩略图和制作元数据。相同来源版本复用副本。
- 项目素材显示来源及使用位置。仍被引用的项目素材不能归档或删除。
- 详情页分为分集、制作资源、成果、成员与设置。项目列表可筛选创建和参与关系。

- 后端全量测试：414 项通过。最终使用 Node 22、`--test-concurrency=4`。
- 前端全量测试：150 项通过。production build 成功。

- 同一集成测试覆盖上传权限与上传去重；模拟生成期间的人工修改，并通过 HTTP 比较、应用保留结果。
- `toolRunHttpBilling.integration.test.js`：模拟 HTTP 供应商，验证发起人付款、伪造付款人无效、移除后结算、其他成员不可重试、私人账单隔离、重启不重复调用。

- 内置浏览器使用两个隔离登录会话。验证详情、制作列表和画布之间的中文双向同步、角色切换、断线文本恢复、后端重启和个人视口隔离。

## 兼容范围

新建及新导入项目默认启用。旧项目只有负责人明确启用后才进入协作机制。

旧项目、历史任务、账本、媒体路径和旧画布 metadata 不做批量改写。旧画布视口仅作为个人视图的初始值。重启测试确认未启用项目的内容与 metadata 保持可读且不对成员开放。

自动素材副本只处理启用后新增或改变的引用。普通保存中的未改动旧引用保持原值，不批量复制历史私人引用。项目副本不会跟随个人原件更新或删除。

旧客户端仍可使用无版本写接口。文本替换会使旧文档版本失效，当前页面未确认的草稿会保留。第一版不提供关闭页面后的离线草稿恢复，也不提供完整版本历史界面。

当进程在操作受理后、结果确认前退出时，该操作保持“结果未确认”。客户端需刷新核实结果，不自动重放生成请求。
# 制作资源导入验收（2026-09-10）

## 资源选择、成果与危险选项

素材导入窗口支持多选后统一提交，成功项从选择中移除，失败时保留其余选择。制作资源卡支持点击及键盘打开编辑。分集删除采用右侧文字入口，并保留删除确认。

成果 API 新增分镜名称和编号字段；旧字段不变。成果按集分组，卡片显示分镜名称；无名称时显示分镜编号，成片单独标为“本集成片”。不改写历史生成记录或媒体路径。

负责人可明确选择当前项目成员转让管理权。转让在事务中更新项目负责人、成员角色和项目素材管理关联；原负责人保留编辑权限。JWT、账号角色、生成发起人、任务及账本归属不变。未明确转让的历史项目不受影响。删除复用原有软删除流程，并在项目名称确认后执行；活跃视频任务返回明确冲突提示。

协作请求和 WebSocket 消息复用 `createClientRequestId`，在不提供 `crypto.randomUUID` 的 HTTP 环境中仍可生成请求 ID。后端的 Node.js UUID 调用保持原样。

消费者检查覆盖项目列表/详情、成员权限、Cookie/JWT 身份、WebSocket 权限刷新、项目素材和本地媒体、生成任务归属、删除路由、成果读取以及刷新/重启恢复。验证通过：后端 426 项、前端 153 项、production build；补充 HTTP 转让/删除/成果集成测试、素材管理关联、重启恢复、UUID 兼容和成果分组测试。内置浏览器检查 1280×720、1440×900、1920×1080 及窄屏，并实际完成多选导入、卡片编辑、分集删除取消、成果筛选、隔离项目转让和名称确认删除。未执行真实生成或生产数据操作。

项目详情只保留一套角色、场景和道具列表。用户明确点击导入后，`POST /dramas/:id/resources/import` 从全局素材创建制作条目，并复制已持久化的图片和角色四视图。相同名称返回冲突，不覆盖现有条目。制作页通过“从项目选择”将资源加入当前集。

新行为只作用于本次及发布后明确导入的条目。历史制作条目、全局素材、历史项目库、任务和账本不迁移、不清理。历史项目库有数据时仍保留选择和编辑入口。相同内容的素材映射同步不再写入数据库，避免只读刷新持续增加协作版本。

消费者检查覆盖：详情列表和编辑、前端 API、导入路由、项目鉴权和操作去重、全局库读取权限、角色四视图与本地/OSS 存储读取、素材映射、制作页角色/场景/道具选择、旧库 CRUD、刷新和重启读取。未引入供应商请求或计费路径。

验证：后端 425 项测试通过，包含 HTTP 导入、重复/非法请求、编辑者/只读成员/非成员权限、图片独立副本、缺失图片回滚、原素材和历史库不变、重启恢复及只读映射版本稳定性。前端 151 项测试及 production build 通过。内置浏览器在 1280×720、1440×900、1920×1080 检查详情页与制作页，实际执行三类导入和加入本集、角色编辑、刷新、历史库读取及末尾操作；窄屏检查资源工具栏和选择弹窗。
# 预览连接与资源编辑窗口补充验收

资源编辑窗口统一使用 720px 默认宽度，并限制在 94vw 内。角色、场景、道具页面已检查 1280×720、1440×900、1920×1080 和 390px 窄屏；取消及保存入口可达。

PR #41 在 PR #40 后部署时，将共享 Nginx 配置覆盖为缺少 Upgrade 转发头的旧版本。外部握手落入 Express 普通 HTTP 鉴权并返回 401。现在每个新部署预览生成精确域名路由，旧预览仍保留共享路由；不更改生产路由、项目数据、任务或账本。预览移除同步删除自身路由并重载 Nginx。

消费者检查覆盖协作 WebSocket、会话 Cookie、预览入口、部署及移除脚本。真实 Nginx 测试同时建立两个预览路由，验证 101 握手；覆盖旧共享配置并重载后再次验证。部署 smoke 还检查无应用会话的升级请求由 WebSocket 鉴权返回 403。合并 Node 24 主分支后，后端 435 项、前端 153 项测试及 production build 通过，部署安全测试和三档桌面及窄屏复查通过。
