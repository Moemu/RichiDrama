# 项目协作实现与本地验收

本次范围为本地代码实现和验收，不含提交、推送或部署。

## 行为

- 项目保留负责人。负责人按准确用户名添加编辑成员或只读成员。
- 编辑成员共同编辑分集、分镜、资源、项目设置和画布布局。分集负责人只表示分工。
- 生成由发起人使用自己的模型权限、配置和余额。移除成员不会改变已提交任务的付款授权。
- 文本使用 Yjs 和 WebSocket。SQLite 在同一事务保存文档快照与业务文本，之后发送确认。
- 普通字段只发送改动值。结构操作带操作 ID 和项目版本；过期操作返回冲突。
- 操作记录在业务执行前持久化。已完成请求返回原结果；未确认请求不会自动重放生成。
- AI 回写遇到人工修改时，保留待应用内容。用户比较后决定是否应用。
- 画布布局和工作流分组共享；视口按当前用户和项目保存在本机。
- 个人素材首次保存为项目引用时，复制本地媒体、缩略图和制作元数据。相同来源版本复用副本。
- 项目素材显示来源及使用位置。仍被引用的项目素材不能归档或删除。
- 详情页分为分集、制作资源、成果、成员与设置。项目列表可筛选创建和参与关系。

## 消费者覆盖

| 范围 | 覆盖入口与处理 |
| --- | --- |
| 项目与子资源 | `ownershipGuard`、项目列表/详情、分集、分镜、角色、场景、道具、分集负责人。保持跨项目关联校验。 |
| 文本与业务写入 | 详情、制作列表、画布、提示词编辑器、项目资源库；文本白名单、字段快照、兼容写入的文档版本失效。 |
| 结构操作 | 分集增删、分镜排序、资源关联、画布布局与工作流；版本检查、操作去重、删除后的编辑拒绝。 |
| 图片与视频 | 图片/视频列表和详情、项目结果、生成权限和原发起人重试边界。 |
| Omni | 项目内生成结果共享、采用结果、任务读取；不开放成员的私人请求数据。项目外序列保留个人权限。 |
| 工具与异步任务 | 工具运行列表/详情、任务项目关联、发起人固定、移除后继续结算、重启读取。 |
| 媒体与素材 | `/static`、媒体上传、项目素材、个人素材自动副本、角色/场景/道具引用、分镜与生成参考。 |
| 成片 | 视频合成的项目权限、历史成片读取、项目成果入口。 |
| 计费 | 登录用户进入既有预授权和结算链；客户端指定付款人无效；其他成员不能代为重试付费任务。 |
| 新建与导入 | 普通新建和新导入项目启用协作；不迁移旧项目引用或账本。 |

消费者检索覆盖 `frontweb/src`、`backend-node/src` 和 `backend-node/test`，包括所有者、项目 ID、素材路径、生成状态和异步任务引用。

## 验证

- 后端全量测试：414 项通过。最终使用 Node 22、`--test-concurrency=4`。
- 前端全量测试：150 项通过。production build 成功。
- `projectCollaboration.integration.test.js`：隔离 SQLite、HTTP 和两个 WebSocket 客户端，覆盖角色矩阵、中文文本合并、重复更新、旧文档冲突、操作去重、删除/排序冲突、素材复制与删除保护、真实本地媒体读取、成员撤销和重启恢复。
- 同一集成测试覆盖上传权限与上传去重；模拟生成期间的人工修改，并通过 HTTP 比较、应用保留结果。
- `toolRunHttpBilling.integration.test.js`：模拟 HTTP 供应商，验证发起人付款、伪造付款人无效、移除后结算、其他成员不可重试、私人账单隔离、重启不重复调用。
- `projectSnapshots.test.js`：验证嵌套接口不会污染项目、分集和分镜的字段基线。
- 内置浏览器使用两个隔离登录会话。验证详情、制作列表和画布之间的中文双向同步、角色切换、断线文本恢复、后端重启和个人视口隔离。
- 页面验收覆盖 `1280×720`、`1440×900`、`1920×1080`，以及 `390×844` 窄屏。检查项目列表、详情、制作页、画布和项目素材库的导航、滚动、末项、固定区和横向溢出。
- 使用隔离本地媒体检查成果发起人、分集标签和媒体加载。没有执行真实供应商调用或生产操作。

## 兼容范围

新建及新导入项目默认启用。旧项目只有负责人明确启用后才进入协作机制。

旧项目、历史任务、账本、媒体路径和旧画布 metadata 不做批量改写。旧画布视口仅作为个人视图的初始值。重启测试确认未启用项目的内容与 metadata 保持可读且不对成员开放。

自动素材副本只处理启用后新增或改变的引用。普通保存中的未改动旧引用保持原值，不批量复制历史私人引用。项目副本不会跟随个人原件更新或删除。

旧客户端仍可使用无版本写接口。文本替换会使旧文档版本失效，当前页面未确认的草稿会保留。第一版不提供关闭页面后的离线草稿恢复，也不提供完整版本历史界面。

当进程在操作受理后、结果确认前退出时，该操作保持“结果未确认”。客户端需刷新核实结果，不自动重放生成请求。
