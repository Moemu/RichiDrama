# 创作闭环与工作台体验改进

## 当前闭环

`灵感/剧本 → 分析或创作 → 素材选择/上传 → 图片或视频生成 → 素材库 → 全能创作镜头 → 成片 → 首尾帧/素材复用 → 下一镜头或项目`。

系统已经具备上述节点，但此前入口以 ID、URL 和孤立页面为主，用户需要自行记住来源与下一步，导致操作生硬。

## 已实施

| 环节 | 改进 | 用户结果 |
| --- | --- | --- |
| 工具输入 | 统一素材选择器，支持素材库点选与本地上传 | 不再复制素材 ID 或手填本地 URL |
| 反推提示词 | 保存真实 `asset_id` 关联 | 图片、视频来源可追溯且可复用 |
| 图片/视频生成 | 参考素材直接来自素材库；首尾帧分别选择 | 参数输入与素材来源处于同一工作流 |
| 流式分析 | 优先展示 `streamed_text` | 过程和结果以可阅读文本而非 JSON 呈现 |
| 生成结果 | 已有“导入素材库 / 带入全能创作”动作 | 视频结果可直接进入镜头编排 |
| 视觉系统 | 结果、历史、说明、控件统一使用主题令牌 | 浅/深主题都维持足够的文字对比度 |

## 后续建议

1. 将工具结果卡固定为三种下一步：`继续编辑`、`导入素材库`、`加入全能镜头`；无可用下一步时明确说明原因。
2. 为每个工具运行记录保存来源、输入素材和输出素材的关系图；在详情页显示“来自哪里 / 已用到哪里”。
3. 对视频生成提供“进入拼接队列”入口，在全能镜头之外满足成片拼接场景。
4. 将连续镜头操作收敛到“使用上一镜头尾帧 / 使用下一镜头首帧”快捷动作，仍由用户确认，不自动覆盖素材。
5. 将提示词引用编辑器扩展到工具箱；素材卡拖入后生成稳定引用芯片，避免复制编辑后丢失关联。
6. 建立真实 API 健康检查记录：显示模型、首次 token、完成时长、供应商任务 ID、错误建议与重试边界，避免只显示模糊的“处理中”。

## 体验准则

- 文本不使用低对比灰色承担关键信息；状态同时有文字、图标和颜色。
- 任何生成结果在一个点击内能进入下一节点；不能进入时说明阻塞条件。
- 上传是素材库写入操作，完成后自动选中但不自动提交模型，避免意外计费。
- 真实 API 调用保留完整请求快照与供应商任务 ID；重试显式触发，不自动重复扣费。
