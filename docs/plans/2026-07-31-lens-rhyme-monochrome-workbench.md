# LensRhyme 黑白工作台视觉与闭环改造

## 背景与定位

LocalMiniDrama 是本地短剧的创作与生产工作台，不是营销落地页。界面应让用户始终知道：自己正在处理哪个项目、哪个镜头、哪项素材或任务，以及下一步可以去哪里。视觉参考 `C:\Users\EDY\Desktop\lens-rhyme` 的克制中性色工作区：紧凑文字层级、低饱和表面、细边界和大面积可工作的画布。

本次以黑、白、灰为唯一基础视觉语言；不使用紫色、紫色渐变、装饰性玻璃拟态或大面积渐变。成功、警告、失败仅用于状态，不承担品牌色职责。全能创作等高密度工作区采用石墨灰与暖白，不使用纯黑、纯白大面积对撞，以保证素材、视频舞台、表单和状态的层级可读。

## 统一组件规范

- 所有按钮使用 6–8px 圆角，主按钮黑白反差，次按钮透明表面与细描边；不使用彩色渐变。
- 卡片只在“可选择对象”或“独立结果”场景出现；卡片内不嵌套装饰卡片。
- 输入、下拉、多选与标签采用同一边框、焦点环和 36px 控件高度。
- 列表选中只使用边框、反转文字或 2px 左边线，不能依赖颜色单独表达。
- 视频缩略图默认静帧；悬停或键盘聚焦后静音预览。完整 controls 只出现在中央主播放器或预览弹窗。
- 所有空状态提供一个明确下一步，所有加载/失败状态明确展示其对象和可恢复动作。

## 主界面布局

### 项目首页

顶部只保留品牌、项目搜索、素材库、AI 工具箱和设置。主体为“最近项目”主列表，不做营销 Hero。新建项目和导入剧本作为同级紧凑操作，项目卡显示进度、最后修改时间和继续创作入口。

### 全能创作

沿用专业剪辑工作台的三栏：左侧镜头列表（20%）、中间成片/时间线（55–60%）、右侧素材与提示词检查器（20–25%）。右侧素材、提示词和高级参数使用连续文档流；高级参数默认收起。镜头选择、拖拽插入、首尾帧提取和提交状态均在中间创作主线中可见。

### AI 工具箱

工具箱为工作台导航，而非营销卡片墙。工具页固定三个区域：输入、成果舞台、历史。历史可以打开、复制、导出、删除或导入项目/素材库；每项结果明确返回其上一级工具箱。

### 素材库

素材库按筛选、内容、详情三段组织。认证、上传限制、文件名、来源、可用次数和用途在详情中可查。真人声明/SD2 状态不另开流程：用户勾选后在同一对象上显示认证进度和失败恢复操作。

## 导航与完整闭环

每个非根页面都必须有稳定的“返回”按钮：

1. AI 工具工作台 → AI 工具箱；
2. 全能创作 → 项目列表，或带 `sequence_id` 返回对应项目；
3. 素材库 → 上一可恢复页面，回退不可用时到项目列表；
4. 项目详情 → 项目列表；分镜编辑 → 项目详情；
5. 生成结果 → 素材库、全能创作镜头或项目分镜，且导入后能回到来源运行历史。

已实现的独立媒体闭环：图片/视频结果完成后可直接调用既有资产导入接口；视频导入成功后可携带 `asset_id` 跳转至全能创作，目标镜头自动选中该素材。

关联动作只能传递真实 ID（`drama_id`、`sequence_id`、`shot_id`、`asset_id`、`tool_run_id`），不得以本地 URL 或纯显示名维持关系。面包屑/返回按钮应保存 query 上下文，避免用户在闭环中丢失当前对象。

## 验收

- 无紫色或紫色渐变的可见界面；全局主控件只使用灰阶黑白。
- 所有主页面采用统一边界、圆角、控件高度、文字层级与状态表达。
- 每个工作台均可从结果进入下一步，也可稳定返回来源。
- 全能创作中间视频舞台保持最大视觉比重；素材和提示词不挤占主创作区。
- 前端测试、后端测试、生产构建均通过。
