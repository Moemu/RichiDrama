# 本地短剧助手桌面端 UI 重构实施方案

## 1. 重构范围

本轮只设计和验收桌面端，覆盖以下分辨率：

- 1280 × 720：最低可用桌面尺寸；
- 1440 × 900：主要设计与验收尺寸；
- 1920 × 1080：宽屏延展尺寸。

不设计手机导航、移动端抽屉、触屏专用布局或 390px 适配。

本轮只重构前端表现层，必须保持以下内容不变：

- API 路径、请求字段、响应字段和状态值；
- 登录、权限、计费、生成、上传、下载和异步任务逻辑；
- Pinia 状态语义、路由业务语义和历史数据读取方式；
- 已有项目、分镜、素材、生成记录和账单记录的业务含义。

## 2. 目标

重构后的产品应呈现为“影视创作工作室”，而不是“后台管理系统”。

必须达到：

- 主页第一屏有明确的项目焦点、继续创作入口和最近记录；
- 创作页始终以画面、镜头或剧本为中心，参数只作为辅助；
- 工具栏不堆满同权重按钮，主操作、次操作和账户操作分层；
- 菜单、选择器、提示层和对话框轻量、稳定，不遮挡关键文字；
- 页面只保留帮助当前任务的文案，不放装饰性英文、无意义标语和重复说明；
- 1280px 宽度下无页面级横向滚动，无操作区被挤出视口；
- 页面切换、展开、收起、选择、保存和加载都有及时但克制的反馈；
- 不再依赖持续追加 `!important` 和页面尾部覆盖规则维持视觉一致性。

## 3. 当前实现审计

### 3.1 工程结构问题

| 现状 | 直接影响 | 重构要求 |
|---|---|---|
| `App.vue` 只渲染 `router-view` | 每个页面各自实现头部、返回、账户和工具栏 | 建立共享 `AppShell`，页面只提供内容区和页面级操作 |
| `theme.css` 约 835 行，包含约 396 个 `!important` | 全局兼容层与页面局部样式互相覆盖，修改一处会影响多页 | 拆为令牌、基础组件、浮层和页面布局四层；删除兼容性覆盖链 |
| `FilmCreate.vue` 约 12147 行 | 业务、布局、浮层、样式和响应逻辑混在同一文件 | 先提取表现型组件，再迁移视觉，不改业务 composable 和 API 调用 |
| `FilmList.vue` 约 2024 行 | 主页存在多轮样式追加和互相覆盖 | 重写主页 DOM 与样式层，保留数据加载和业务操作 |
| `AIConfigContent.vue` 约 2852 行 | 大量表单、表格和弹窗形成典型后台界面 | 改为分区式配置工作台，复杂信息按需展开 |
| 多页面重复 `.header`、`.topbar`、`.workbench-header` | 高度、间距、按钮顺序和滚动规则不一致 | 统一产品头部和工作区头部 |
| 页面大量 `height: 100dvh`、`overflow: hidden`、固定定位 | 长文案、状态提示和浮层容易被裁切或遮挡 | 每页只允许明确的主滚动容器；文字容器不得用固定高度截断 |

### 3.2 当前桌面页面实测

#### 主页 `/`

- 真实媒体主舞台已形成视觉焦点，可以保留这一方向；
- 顶栏同时放置主导航、余额、主题、导入、新建和更多，优先级混乱；
- “更多”菜单承载全能视频、工具箱、导入、已删除、配置、账户、后台和退出，像后台操作菜单；
- 菜单打开后直接覆盖右侧创作记录；
- 创作记录使用固定侧滑层覆盖主页，打开后会中断对主舞台的阅读；
- 大标题、项目数据和最近记录均使用绝对或固定式排布，后续增加文字时风险高。

#### AI 工具页 `/ai-tools`

- 左右分栏具备视觉差异，但装饰性英文较多；
- `RICH MEDIA · AI STUDIO`、`INPUT / CRAFT / SCREEN`、`SELECT A CAPABILITY` 不帮助完成任务；
- 工具列表文字偏小，输入与产出信息横向压缩，可读性不足；
- 页面更像作品集展示页，工具筛选、最近使用和任务继续入口不足。

#### 全能创作 `/free-create`

- 左侧镜头、中央舞台、右侧参数的三栏方向正确；
- 左侧镜头卡片内同时放置序号、拖拽、上移、下移、重命名、删除、时长和状态，信息密度过高；
- 中央视频舞台下方提示词区域被上下工具条挤压；
- 右侧连续堆叠选择器、说明、计费提示、素材和历史记录，形成参数后台；
- 模型选择器直接显示原始模型 ID；
- 模型菜单向左覆盖中央提示词区域，菜单宽度和层级明显过重；
- 左、中、右三个区域都有独立滚动，缺少明确的滚动归属。

### 3.3 浮层与选择器影响面

当前至少存在以下高频消费者：

| 区域 | 主要文件 | 现状 |
|---|---|---|
| 主页导航菜单 | `views/FilmList.vue` | 2 组下拉菜单，菜单承担过多路由 |
| 项目创作 | `views/FilmCreate.vue` | 25 个选择器、11 组下拉、19 个对话框、6 组标签页 |
| 全能创作 | `views/FreeCreate.vue` | 模式、模型、素材用途等选择器位于窄右栏 |
| 画布 | `views/DramaCanvas.vue`、`components/dramaCanvas/*Panel.vue` | 部分浮层已传送到 `body`，但尺寸和层级仍不统一 |
| AI 配置 | `components/AIConfigContent.vue` | 12 个选择器、8 个对话框、18 组表格 |
| 后台管理 | `views/AdminConsole.vue` | 筛选、表格、抽屉和对话框并存 |
| 通用生成参数 | `components/GenerationSettings.vue` | 7 个连续选择器构成表单墙 |

浮层规范必须一次覆盖这些消费者，不能只修主页菜单。

## 4. 目标信息架构

### 4.1 一级导航

全局头部只保留四个一级入口：

1. 项目；
2. 素材；
3. AI 工具；
4. 全能创作。

右侧只保留：

- 可用余额；
- `新建` 主按钮；
- 账户头像菜单。

以下内容移入账户菜单，不在顶栏单独占位：

- 主题切换；
- AI 配置；
- 账户中心；
- 后台管理；
- 退出登录。

“导入项目”放入 `新建` 按钮的次级入口，不再单独常驻顶栏。

### 4.2 页面层级

| 层级 | 用途 | 示例 |
|---|---|---|
| 产品头部 | 全局导航、余额、新建、账户 | 所有登录后页面 |
| 工作区头部 | 返回关系、当前项目、保存状态、核心动作 | 项目详情、创作页、画布、工具工作台 |
| 工作区主体 | 当前任务的主要对象 | 剧本、镜头、画面、素材、生成结果 |
| 检查器 | 参数、属性、补充信息 | 生成参数、镜头属性、素材引用 |
| 浮层 | 临时选择或确认 | 菜单、轻提示、删除确认、图片预览 |

不新增 UI 框架，不引入第二套组件库。

### 5.2 `AppShell`

- 固定产品头部高度 64px；
- 内容区高度为 `calc(100dvh - 64px)`；
- 产品头部只负责全局导航，不放页面级表单；
- 页面自行声明 `content`、`rail`、`inspector` 三个插槽；
- 全局浮层统一挂载到一个浮层根节点；
- 页面切换后主内容获得焦点，保留键盘导航顺序；
- 页面级滚动和工作台内滚动二选一，禁止同时存在无归属的滚动条。

| 区域 | 1280 × 720 | 1440 × 900 | 1920 × 1080 |

| 左侧轨道 | 220px | 240px | 264px |
| 右侧检查器 | 312px | 336px | 360px |
| 区域间距 | 12px | 16px | 20px |
| 中央工作区 | 剩余宽度，最小 640px | 剩余宽度 | 最大 1120px 后居中延展 |

当 1280px 下中央区域不足 640px 时，优先收窄左右栏，不缩小正文和按钮文字。

## 6. 视觉系统

### 6.1 色彩

暗色模式作为创作工作台默认模式，浅色模式保持同一层级关系。

```css
--canvas: #090c12;
--surface-1: #0f141d;
--surface-2: #151c27;
--surface-3: #1c2533;
--surface-hover: #222d3d;
--surface-selected: #28354a;

--text-1: #f5f7fb;
--text-2: #c8cfda;
--text-3: #909aaa;

--line-1: rgba(255, 255, 255, .08);
--line-2: rgba(255, 255, 255, .16);

--accent: #7c6cf2;
--accent-hover: #8d7ff7;
--focus: #9b8cff;

--success: #45bf91;
--warning: #e7ad4e;
--danger: #eb6b78;
--info: #72aef2;
```

约束：

- 页面背景最多使用一层低对比环境光，不持续动画；
- 媒体舞台可以保持纯黑或近黑；
- 不在每个卡片上使用渐变、发光和重阴影；
- 状态色只用于状态，不用于普通装饰；
- 浅色模式不重新发明布局，只替换同名语义令牌。

### 6.2 字体

| 用途 | 字号 / 行高 | 字重 |
|---|---|---:|
| 页面主标题 | 36–56 / 1.08 | 650–720 |
| 工作区标题 | 24–32 / 1.2 | 650 |
| 区块标题 | 18–22 / 1.3 | 600 |
| 正文 | 15 / 1.6 | 400 |
| 表单标签 | 14 / 1.4 | 550 |
| 辅助文字 | 13 / 1.5 | 400 |
| 状态与数字 | 13–15 / 1.4 | 550，数字使用等宽数字 |

禁止：

- 用 10px–11px 英文装饰文字制造层级；
- 用全大写英文替代真实中文标题；
- 为了塞入一行而缩小正文；
- 在按钮中放超过一个动作含义。

### 6.3 间距、圆角和阴影

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 20px;
--space-6: 24px;
--space-8: 32px;
--space-10: 40px;
--space-12: 48px;

--radius-control: 8px;
--radius-panel: 12px;
--radius-dialog: 16px;
```

- 输入框和按钮高度统一为 40px；
- 主要按钮高度可用 44px；
- 图标按钮可视尺寸 36px，点击区域不小于 40px；
- 面板主要依靠背景和 1px 边线分层；
- 浮层仅使用一档阴影，不给普通卡片增加悬浮阴影。

## 7. 文案与零遮挡规范

### 7.1 文案准入

页面文案只允许属于以下四类：

1. 当前对象：项目名、镜头名、素材名、模型名；
2. 当前状态：草稿、处理中、已完成、失败、保存时间、余额；
3. 当前动作：新建、继续制作、生成、保存、导入、删除；
4. 必要说明：输入要求、限制、计费、错误原因和恢复方式。

删除或改写：

- `SELECT A CAPABILITY`；
- `INPUT / CRAFT / SCREEN`；
- `DIRECTOR CONSOLE`；
- `SHOT TRACK`；
- `AI RUN STUDIO`；
- `INPUT DECK`；
- `RUN ARCHIVE`；
- `OUTPUT STAGE`；
- 其他只起装饰作用、与当前任务无关的英文标签。

品牌名可以保留，但同一屏只出现一次。

### 7.2 零遮挡硬规则

- 标题、表单标签、错误、计费说明、生成状态和按钮文字不得被 `overflow: hidden` 裁切；
- 文本容器不使用固定高度；必须使用内容高度或明确的内部滚动；
- 两行以上的说明使用自然换行，不使用单行省略；
- 项目名、素材名允许单行省略，但必须提供完整 `title` 或可聚焦提示；
- 按钮文字不得被图标、加载动画或角标覆盖；加载时按钮宽度保持不变；
- 固定头部不得覆盖页面首行，工作区必须显式扣除头部高度；
- 粘性工具栏不得覆盖错误提示、保存状态或当前输入；
- 页面级 `scrollWidth` 不得大于 `clientWidth`；
- `z-index` 只能使用统一层级令牌，不允许页面自行写任意大数值；
- 浮层打开时不得覆盖当前输入内容、错误信息和生成状态。

## 8. 菜单、下拉框与浮层

### 8.1 浮层层级

```css
--z-header: 100;
--z-sticky: 200;
--z-popover: 400;
--z-dialog-backdrop: 600;
--z-dialog: 610;
--z-toast: 800;
```

禁止在页面局部样式中出现 1000、2000、9999 等任意层级。

### 8.2 顶栏菜单

使用 `UiMenuPopover` 替代主页的重型“更多”菜单。

- 菜单宽度 192–224px；
- 触发器与菜单间距 8px；
- 菜单内边距 6px；
- 菜单项高度 40px；
- 菜单项文字 14px；
- 只允许一个主标签和一个可选快捷键，不放长说明；
- 分组使用 1px 分隔线和 6px 间距；
- 背景使用 `surface-2`，边框使用 `line-2`，不使用大面积毛玻璃；
- 自动检测视口碰撞，必要时左右翻转；
- `Esc` 关闭，关闭后焦点返回触发器；
- 点击外部关闭；
- 触发器必须同步 `aria-expanded`。

主页不再保留“更多”入口。账户、配置、后台和退出统一进入头像菜单；新建与导入进入 `新建` 组合入口。

### 8.3 工作台参数选择器

右侧检查器内的模型、分辨率、时长、插帧、宽高比和素材用途，不继续使用覆盖中央内容的大型弹出菜单。

改为 `UiChoiceField`：

- 默认显示标签、当前值和展开箭头；
- 点击后在右侧检查器内部原位展开，使用正常文档流推开下方字段；
- 选项区最多显示 6 项，超出后仅选项区滚动；
- 选项高度 40–48px；
- 当前项同时使用勾选图标和背景，不只依赖颜色；
- 支持方向键、Enter、Space 和 Esc；
- 展开时不改变右侧检查器宽度；
- 不覆盖中央提示词、视频舞台、错误和状态信息。

模型选项的用户可见格式：

```text
Seedance 2.0
标准版 · 支持多参考 · 720p
```

原始模型 ID 只在 AI 配置和管理员页面显示；普通创作页不直接显示 `doubao-seedance-2-0-260128`。

### 8.4 对话框

- 创建、编辑等短表单宽度 480–560px；
- 复杂配置不放 90% 宽大弹窗，改为独立页面或右侧检查器；
- 对话框标题固定，正文独立滚动，底部操作固定但不覆盖正文；
- 底部为“取消 + 主操作”，危险操作不得与主操作同色；
- 打开时聚焦标题后的首个可操作控件；
- 关闭后返回原触发器；
- 错误信息显示在对应字段下方，不只用消息提示。

## 9. 页面改造

### 9.1 主页 `/`

保留真实媒体主视觉，重写页面结构为：

```text
产品头部
└─ 主工作区
   ├─ 当前项目主舞台
   │  ├─ 项目类型与状态
   │  ├─ 项目名称
   │  ├─ 集数、分镜数、更新时间
   │  └─ 继续制作 / 新建项目
   └─ 最近创作侧栏
      ├─ 最近项目
      ├─ 处理中任务
      └─ 查看全部记录
```

具体修改：

- 删除固定的 `records-scrim` 和覆盖式 `records-workspace`；
- 最近记录常驻右栏，完整记录切换为主工作区内的“全部项目”视图；
- 右栏与主舞台使用真实网格，不用绝对定位互相叠放；
- 项目名最多两行，不允许被右侧记录覆盖；
- 背景视频只做主舞台背景，增加稳定的静态遮罩保证文字对比度；
- 背景视频不再持续缩放呼吸，避免长时间 GPU 动画；
- 主按钮只保留“继续制作”，次按钮为“新建项目”；
- 数据统计降低权重，不与主按钮争夺注意力；
- 空状态只显示创建、导入和必要说明，不显示装饰标语；
- 主页首屏不使用卡片墙，不使用后台式数据表。

### 9.2 项目详情 `/drama/:id`

- 顶部显示项目名、状态、画面比例、更新时间和两个主入口：继续制作、画布模式；
- 集数改为时间线式列表，突出当前集、分镜数量、完成进度和最近更新；
- 角色、场景、道具和媒体统一进入“项目素材”页签；
- 编辑项目信息使用右侧检查器，不在页面中连续堆叠表单；
- 删除、导出等低频操作进入项目菜单；
- 集数标题和描述自然换行，操作区不能覆盖标题。

### 9.3 项目创作 `/film/:id`

目标骨架：

```text
工作区头部：项目 / 当前集 / 保存状态 / 预览 / 生成
左侧：剧本 → 素材 → 分镜 → 合成
中央：当前阶段主内容
右侧：当前对象属性与生成参数
```

实施要求：

- 将 `FilmCreate.vue` 的表现层拆为阶段容器和独立面板；
- 顶部快捷导航与左侧步骤导航合并为一套；
- 当前阶段只显示当前任务所需控件，不同时暴露全部生成参数；
- 分镜卡片只显示序号、画面、标题、状态和主要动作；
- 角色、场景、道具添加菜单迁移到统一轻菜单；

## 10. 动效与反馈

### 10.1 动效令牌

```css
--motion-fast: 140ms;
--motion-standard: 220ms;
--motion-slow: 320ms;
--ease-standard: cubic-bezier(.2, 0, 0, 1);
--ease-out: cubic-bezier(.22, 1, .36, 1);
```

### 10.2 使用范围

- 按钮 hover：边框、背景、文字，140ms；
- 按钮 active：`scale(.98)`，80–120ms；
- 菜单：`opacity + translateY(4px)`，160ms；
- 检查器折叠：`opacity + grid-template-rows`，220ms；
- 对话框：遮罩淡入和面板轻微缩放，220ms；
- 页面切换：仅主内容 `opacity + translateY(6px)`，220ms；
- 加载：局部骨架或保持旧内容，不显示整页白屏。

禁止：

- `transition: all`；
- 背景持续旋转、呼吸和大范围缩放；
- 每张卡片同时漂浮；
- 动画 `width`、`height`、`top`、`left`；
- 超过 420ms 的常规交互动画；
- 依赖大面积 `backdrop-filter` 维持视觉效果。

必须保留 `prefers-reduced-motion`，关闭位移和持续动画。

## 11. 样式治理

### 11.1 层级顺序

样式加载顺序固定为：

1. `tokens.css`：颜色、字体、间距、尺寸、层级和动效；
2. `base.css`：重置、排版、焦点和滚动条；
3. Element Plus 原始样式；
4. `element-plus.css`：对组件库的单层语义映射；
5. `overlays.css`：菜单、选择器、提示、对话框；
6. `workspaces.css`：共享工作台骨架；
7. 页面局部样式：只描述本页排布。

### 11.2 约束

- 新增样式不得使用 `!important`；
- 旧 `theme.css` 逐段迁移后删除对应兼容规则；
- 页面局部样式不得直接覆盖 `.el-popper`、`.el-dialog` 等全局类；
- 页面局部样式不得定义新的全局颜色；
- 页面局部样式不得写任意 `z-index`；
- 组件状态通过 `data-state` 或语义 class 表达，不依赖深层 DOM 选择器；
- 一次迁移一个路由，迁移完成后删除该路由的旧样式，不保留双套视觉。
