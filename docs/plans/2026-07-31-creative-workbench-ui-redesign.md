# 2026-07-31 创作工作台 UI 重构规范

> 状态：实施中  
> 适用范围：AI 工具箱、六个独立工具工作台、Free-create 全能视频创作、相关任务与素材状态。

## 1. 产品定位与设计结论

LocalMiniDrama 不是展示型 AI 网站，而是面向漫剧制作流程的本地创作台。用户的主要判断顺序是：**现在在做哪一个镜头 → 正在生成什么 → 可用哪些素材 → 下一步如何继续**。因此页面必须优先呈现工作对象和成果，而不是把模型、提示词、历史记录平铺成同等重量的表单。

### 核心原则

1. **成片优先**：视频主画面是 Free-create 的视觉中心，至少占据桌面有效工作区的一半。
2. **渐进披露**：模型、比例、音频等设置集中在可折叠的检查器；素材与提示词共同构成“创作输入”，不与主画面争夺注意力。
3. **连续性可见**：镜头列表同时呈现顺序、时长、状态和预览，镜头之间的前后关系不藏在二级页面。
4. **任务有安全感**：每个生成动作给出明确的“已保存 / 队列中 / 生成中 / 可重试 / 已完成”状态与最近保存时间，历史通过可展开的侧栏查看，而非只显示裸文本。
5. **无误导的能力边界**：首尾帧、SD2 认证、参考音频、模型限制在输入区就给出可操作的槽位和剩余数量。

## 2. 视觉系统

### 色彩令牌

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面底色 | `#10151D` | 深石墨，降低长时间创作的眩光 |
| 工作区表面 | `#181F29` | 面板底色 |
| 浮层 / 卡片 | `#202936` | 与页面拉开一级层次 |
| 分隔线 | `#334050` | 低对比但足够清晰 |
| 主强调 | `#4B91C8` | 冷蓝，仅用于主动作、当前选择与焦点 |
| 次强调 | `#C48A4A` | 铜色，用于时长、排队、待处理提示 |
| 成功 | `#4FA77A` | 已完成、可用 |
| 警告 | `#D6A854` | 限制、待认证、可重试 |
| 错误 | `#D66B6B` | 失败、阻断 |
| 文本 | `#F2F0EA` / `#AAB4C0` | 暖白主文本与灰蓝次文本 |

禁止使用紫色、紫色渐变及大面积装饰性渐变；不采用玻璃拟态。背景只使用实色、细边框和极轻阴影。

### 排版与交互

- 采用 8px 间距体系；标题 20–28px，区块标题 14–16px，辅助信息 12px。
- 所有状态同时使用图标、文字与颜色；不可只靠色彩区分。
- 明确可点击范围、hover、键盘焦点和禁用原因；`prefers-reduced-motion` 下关闭循环动效。
- 视频缩略图默认静帧；仅 hover / focus 后静音预览。主播放区才提供完整控制条。

## 3. 信息架构

### 3.1 Free-create（三栏镜头工作台）

```
镜头导航（20%）   成片 / 时间线（55–60%）    创作检查器（22–25%）
顺序、缩略图、状态   当前成片、进度、首尾帧       模式、输入素材、提示词、设置
```

- 左栏固定：镜头顺序、拖动插入提示、上/下移动、镜头状态、首尾帧来源。
- 中栏优先：主视频 16:9 / 9:16 自适应，空状态也展示当前输入素材拼贴与下一步动作；视频下方保留时长轨道和镜头脚本文档。
- 右栏按顺序显示：模式 → 必填槽位 → 素材 → 提示词 → 高级参数 → 生成。高级参数默认收起。
- 窄屏变为：主视频 → 生成动作 → 镜头横向列表 → 创作输入；不隐藏状态或素材限制。

### 3.2 AI 工具箱（任务入口）

- 顶部说明“独立保存、按需导入项目”，并提供最近运行数量和素材库快捷入口。
- 六张工具卡根据输入类型分组：文本策划、视觉生成、视频工作流；每张卡说明输入、输出与保存位置。
- 卡片不做营销式大图，采用功能图标、信息标签和明确的“进入工作台”操作。

### 3.3 独立工具工作台

- 桌面布局为：**输入检查器（280px）—运行历史（260px）—成果舞台（自适应）**。
- 结果区优先结构化结果、媒体预览与可执行操作；原始 JSON 作为切换视图而非默认唯一内容。
- 历史项显示标题、状态、更新时间、失败原因摘要；运行中显示进度而不只显示“processing”。
- 生成媒体工具采用大预览网格及参数抽屉，不把历史列表放在成片预览之前。

## 4. 落地验收

- Free-create 的中栏在 1440px 视口占至少 55% 宽度，主视频明显大于左右栏。
- 不出现 `#6c8cff`、`#6d8bff`、`#7f9aff` 等紫蓝色遗留强调；新/修改 UI 使用蓝、铜、绿、黄、红语义色。
- 工具箱和工作台均可在 900px 以下转为单栏或按逻辑堆叠。
- 已完成、生成中、失败、可重试、草稿状态均有文字、图标、颜色。
- 通过前端构建；用本地浏览器检查 `/ai-tools`、一个工具工作台和 `/free-create` 的桌面与窄屏布局。
