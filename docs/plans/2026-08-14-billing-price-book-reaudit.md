## 1. 结论

界面显示 Seedream 5.0 为 `0.0022 积分/张` 是错误的。正确价格为人民币 `0.22 元/张`，按本项目兑换口径应为 `22 积分/张`。

根因不是报价公式，而是旧迁移 `37_points_ratio_and_volcengine_video_prices.sql` 每次启动都会重放。数据库已完成微积分精度迁移后，它仍把图片字段写成整数 `22`；读取层再按 `10,000` 除，最终显示 `0.0022`。历史成功图片用量日志仍是每张 22 积分，没有被本次修复重算或篡改。

修复采用双重保护：

1. 旧迁移按 `billing_precision_scale_v2` 标记判断单位：已转换数据库写 `220000` 微积分，新数据库在精度迁移前写 `22` 旧单位。
2. 新迁移 53 再执行一次相同的纠正；自动化测试连续重跑迁移，断言价目仍为 22 积分。

## 3. 闭环规则

- 所有真实供应商调用必须从登录态 `/api/v1/...` 业务路由进入。
- 生成、超分、插帧分别预授权；任一预授权失败时，供应商调用不会开始，已经冻结的后续/前序未消费授权会释放。
- 每段调用独立记录供应商任务 ID、请求 ID、计费快照与 usage；实际规格高于预授权时进入 `billing_reconciliation`，不能静默透支。
- 供应商临时签名 URL 只用于下载；完成态必须指向本地持久化文件。
- 重启按 `source -> upscale -> interpolation` 的依赖顺序恢复；已完成任务幂等读取，不重复提交或重复扣费。

### 3.1 真实默认链路计费复验（2026-08-14）

- 通过登录后的项目 HTTP API 创建 `video_generations.id=61`：720p、9:16、4 秒、超分到 1080p、`target_fps=null`。
- Seedance 按实际 `87300 output_token` 结算 `200.79` 积分。
- 超分按本地探测的 `4100ms / 1080p / 24fps` 结算 `68.3333` 积分，保存 MediaKit request ID。
- 插帧关闭，因此插帧任务、授权、usage 和扣费均为 0；不是先冻结后释放的伪关闭。
- 重启后任务数、流水数和 usage 数不变，账户 `frozen_micro=0`，无待对账。
- 图片单张报价在同一次重启后通过 `POST /api/v1/billing/quotes` 复验为 `22` 积分，不再是 `0.0022`。

## 4. 风险处置

本次没有删除历史 SKU，避免破坏已有任务的价目快照。缺少公开来源的旧文本/TTS SKU 被标记为“未通过外部复核”，且不属于当前默认调用链；若未来启用，应先补控制台账单证据和条件档位，再发布新价目表版本，不能直接覆盖历史账本。

## 5. AI MediaKit 后处理价目显示/兜底修正（2026-08-14）

火山官方“视频工具计费”以元/输出分钟公布，并按毫秒精确计量、换算为分钟。按本项目换算口径 `1 元 = 100 积分`：

| 能力 | 官方价目（积分/输出分钟） |
|---|---|
| 生成式增强（超分） | 720p：250 / 500 / 1000；1080p：500 / 1000 / 2000；2K：1000 / 2000 / 4000（分别为 ≤30 / ≤60 / ≤120fps） |
| 视频插帧 | 720p：60 / 120 / 240；1080p：120 / 240 / 480；2K：240 / 480 / 960；4K：480 / 960 / 1920（分别为 ≤30 / ≤60 / ≤120fps） |

根因：迁移 52、53 写入条件档位时发生在微积分标记落库之前，条件 `rates` 本身正确，但供无 `pricing_context` 使用的基础单价被错误缩放，管理端便显示为“0.0001 积分/60,000ms”和“1 积分/60,000ms”。这不是火山的正式按分钟价目。

修复：迁移 56 只更新官方全局的两个 MediaKit 后处理 SKU 的兜底单价——插帧为 `120 积分/60,000ms`（720p、≤60fps 默认档），超分为 `1000 积分/60,000ms`（1080p、≤60fps 默认档）；前端改为展示完整条件价区间，实际预授权/结算仍以输出分辨率和帧率命中精确档位。例如 1080p、≤60fps 插帧报价为 240 积分/分钟，1080p、≤30fps 超分报价为 500 积分/分钟。

迁移不更新 `billing_transactions`、`billing_usage_logs`、授权快照或用户自定义价目表；既有线上订单、余额和已完成视频均不会被重算或改写。回归覆盖迁移幂等和两条 HTTP 报价规格。
