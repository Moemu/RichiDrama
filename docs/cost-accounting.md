# 客户与项目成本核算一期

实现分支为 `codex/customer-cost-accounting`，基线 `73a2385`。该基线包含供应商连接和模型目录改动，依赖 PR #37。成本核算改动使用独立提交，预览 PR 不代表正式发布。

## 使用入口和口径

运营工作台 → 消耗与成本，页面 `/admin/costs`，API `/api/v1/admin/costs`。所有接口要求运营后台权限。普通用户、客户管理员及无后台权限的管理员不能访问。审计查询的所有权豁免仅限此接口族。

成本台账独立于积分账本。页面分别展示实际用量、供应商成本估算、平台扣费和未确定项。金额按整数微单位保存，汇总显示两位小数；非人民币按原币单列。成本按供应商提交时间归属，积分按原账本结算时间统计，两者差额不直接解释为毛利。

查询支持客户、项目、执行用户、账号、模型、操作类型、成本状态和日期交叉筛选。分组支持客户、项目、用户、模型、操作类型及小时、日、月。调用和分组均由服务器分页。调用详情展示操作、尝试、供应商关联、规格、用量证据、价格版本和修订历史。

客户月报固定客户和自然月。保存生成时的完整结果及证据修订，版本不可覆盖。汇总和全部明细使用登录 Cookie 从服务器流式下载 CSV，包含版本、统计截止时间和“成本估算”说明。管理页的价格、候选来源、月报和补算批次列表当前各展示最近 100 项；已有月报、候选和补算批次仍可按 ID 读取。

## 链路覆盖

| 链路 | 记录位置和验收范围 |
| --- | --- |
| 文本、视觉理解 | `aiClient` 原生 HTTP 提交；工具运行中的多次调用分别记录 |
| 图片 | `imageClient` 实际 POST，包括重试；一次多图响应记录一次请求及实际图片数 |
| 视频 | `videoClient` 实际提交；任务查询仅补充原记录，已知本地媒体时长可补充计量 |
| 语音 | `ttsService` 提交前记录，成功响应按 Unicode 字符计量 |
| 超分、插帧 | 每个实际后处理提交独立记录，继承原操作归属，记录处理时长 |
| 工作流、全能创作、工具箱 | 复用以上客户端及业务预授权上下文；工具 HTTP 验收确认四次文本请求形成四条记录 |

客户、项目、用户名在预授权或首次操作时形成快照。同一操作的重试和子操作继承归属。成员换组、项目转移和改名不修改已存快照。账号来自实际配置的显式绑定，不按供应商标签、域名或模型名猜测，不保存密钥。

提交前持久化失败会阻止供应商提交。提交结果不明保留待核实，不为补记成本重试供应商。响应后成本计算失败保留用量；后续可按原因新增修订。轮询、重复证据及重启不会新增供应商提交。成本记录不会改变平台积分扣费规则。

## 审核价格

先创建供应商账号并绑定配置，再录入草稿，或通过显式选择的 ModelArk IAM 配置读取候选。候选保留来源和原价，审核适用价格、币种、单位、规格、生效时间后发布。已有折扣价格不再次乘折扣。

支持输入、缓存、输出 Token，图片、输入图片、请求数、毫秒、秒和字符。规则可限定输入 Token 档位、视频输入、音频、分辨率、帧率档位、像素档位、图片场景和服务等级。缺少必要规格或用量时不猜价格。规则不匹配或重叠时显示缺价格。

默认选择提交时间内有效的已发布价格。发布新版本不回写旧调用。补齐价格需填写原因，新增成本修订；已有月报保留原结果。

## 新旧数据边界

迁移 `20260908_z_cost_accounting.sql` 只新增成本表和索引。`cost_settings.enabled_at` 是每个数据库实际启用时的覆盖起点，页面显式展示。新调用在迁移启用后自动记录。

历史任务、历史积分、历史价格和发布前已经提交的调用默认不自动补算。恢复处理只更新已有成本调用，不为旧任务虚构记录。历史补算须显式预览和执行，使用来源唯一键防重。

历史补算要求持久化的客户归属、供应商账号、真实用量、价格及时间依据。缺少供应商提交时间时，仅可使用原预授权创建时间，并标记近似。不能使用当前成员名单或当前账号绑定推断历史；缺失或歧义项跳过并显示原因。每批最多检查 1000 条历史账本记录，按日期缩小批次。

一期不包含账单导入、费用分摊、客户侧成本展示、汇率换算、每日自动快照。没有进行真实供应商计费调用；不同供应商的未返回用量和未审核价格仍需运营核实。
