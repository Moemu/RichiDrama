# 主页默认视频访问修复

## 问题与修复

预览主页的三个默认视频使用 `/static/library/videos/...`，页面读取到清单后无法加载视频。
`homepage_default_video_paths` 已指定全局展示资源，但新增媒体权限校验未读取该清单。

主页列表与媒体授权现在共用同一份路径解析结果。仅前三个有效本地视频路径向登录用户开放。
匿名请求仍需登录；同目录、同项目的其他媒体仍使用原有所有权校验。移除清单条目后，授权立即失效。

## 影响面与兼容

检索覆盖 `frontweb/src`、`backend-node/src`、`backend-node/test`：

- `FilmList.vue` 与 `api/videos.js`：列表响应字段不变，无前端修改。
- `/homepage/default-videos`、`videoService`、`settingsService`：列表和授权使用相同规则。
- `/static`、`mediaAuthorizationService`、`mediaStorageService`：保留登录、私有缓存、Range 和本地持久化读取。
- 素材、生成、项目、历史记录：已有所有权规则与测试保持通过。
- 全局设置没有供普通用户写入任意键的接口。

新行为只恢复已显式加入主页展示清单的视频访问；其他历史记录明确排除。
不执行数据库迁移、媒体复制或删除，不触发生成或供应商调用，不修改生产配置。

## 验证

- 后端全量测试：362/362 通过。
- HTTP 集成：三个展示文件、两个账号、匿名 401、Range 206、相邻未共享文件 404、撤销清单授权。
- 关闭并重新打开数据库及 HTTP 服务后，主页接口和媒体内容仍可读取；私有历史媒体仍隔离。
- 路径校验：外部 URL、路径穿越、无效类型及第四个条目不会获得共享授权。

预览实际播放结果在对应 PR 提交的验证记录中交付。
