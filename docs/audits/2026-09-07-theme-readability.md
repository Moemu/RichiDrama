# 浅色与深色模式可读性修复

## 问题与修复

部分页面同时使用固定深色配色和全局主题覆盖。浅色背景生效后，局部白色文字没有同步切换。另一些页面保留深色媒体背景，但全局标题与说明文字变成了深色。

- 分镜与全能视频：素材声明、生成参数标题、身份状态、音频标签、历史空状态改用主题变量。缩略图时长使用独立的深色底和浅色字。
- 画布：分镜正文、集数、模式与工作流标签、新建节点及编辑面板改用语义颜色。加载遮罩继续使用媒体背景上的浅色文字。
- 项目库：无图占位背景跟随主题，避免浅色模式下的灰字落在深色块上。
- 首页、工具目录与登录页：媒体区域的标题、说明和搜索文字使用独立前景色，保留原有媒体与品牌背景。
- 通用控件：提高占位文字、次要导航和状态标签的对比度。主按钮使用单独的背景色，避免深色模式的浅紫强调色使白字失去对比。普通按钮、弹窗按钮和描边按钮分别验证。
- 工具结果区：空结果与结果说明背景跟随主题。

- 前端自动化测试：146 项通过。新增检查覆盖两种主题的正文、次要文字、占位文字、状态文字、媒体字幕与主按钮配色对比。
- Production build 通过。仅保留已有的大 chunk 提示。
- 使用 Codex 内置浏览器，连接隔离的本地 dev 后端与候选前端。后端使用独立数据库和存储，网络保护禁止非本地供应商请求。
- 两种主题均核对 `1280×720`、`1440×900`、`1920×1080`。覆盖首页、项目资源、分镜、全能视频、画布、配置、账户、后台、素材库、工具目录、文字工具、图片工具、视频工具与登录。

- 实际检查了项目搜索与关闭、配置下拉弹层、配置和项目库编辑弹窗、画布编辑面板、创作参数滚动、错误预览、工具目录最后一项、工具结果区、后台底部与固定生成操作。
- 补充 `390×844` 窄屏：首页搜索及关闭、分镜面板切换、参数与最终操作可达；没有页面横向溢出。
- 刷新历史项目后，原有剧集、角色和分镜仍可读。退出并重新登录后，所选主题仍保留。
- 未执行真实生成、付费、生产配置修改或生产数据操作。
