- 权限：注册、JWT/Cookie 登录、全局设置、三种资源库、素材、批量音频、分镜关联、合成列表/详情/删除和媒体读取。已有角色及会话不重写。
- 媒体：上传、素材创建/更新、分镜更新、图片/视频/Omni、素材库、OSS 静态读取和 ZIP 导入导出。完成结果保持本地路径，不改为供应商签名 URL。
- 异步及计费：工具运行、图片租户选择、视频生成、超分、插帧、待对账、取消、分镜状态和启动恢复。恢复不重复提交或结算。
- 分镜合约：前端 API、画布单镜/批量/工作流、统一资源表单、项目嵌套分镜、单分镜详情、Omni 路由、导入导出及重启读取。
- 共享界面：`ToolAssetSelector` 的图片、视频和反推入口；`ToolWorkbench` 的分析、流式分析、创作和反推入口；素材库、首页、账户、路由和任务 store。

共享工具页验收还修复了窄屏输入区与历史/结果区重叠。窄屏改为文档纵向滚动，桌面三栏不变。普通剧本分析不再错误显示反推素材控件。

## 兼容范围

- 新注册和后续写请求使用新的字段及归属校验。没有批量改写旧账号、项目、素材、状态或账本。
- 历史媒体按实际位置和权威归属读取。根目录内旧绝对路径、历史共享库均有测试。归属不明或冲突的路径拒绝访问，不能通过新建素材绕过。
- 后处理恢复列 `postprocess_recovery_version` 默认 `0`，历史记录不自动启用；新建或明确重试任务启用。管理员本次明确结算/豁免产生的恢复标记也属于 opt-in。历史已解决但无标记的对账记录排除。
- 导入新增字段可选，旧 ZIP 仍可导入。仅为新导入项目映射资产，不修改源项目；回滚限定本次写入清单。
- 代表帧清理限定本次临时文件，不扫描历史目录。未执行生产清理、重算、密钥轮换或配置修改。
- 场景/道具新模式使用显式参数；旧调用省略参数时保留原默认模式。

## 验证结果

最终后端全量 **356/356**、前端 **144/144** 通过，production build 成功，`git diff --check` 通过。构建仍提示已有大 chunk。

后端使用 `node --test test/*.test.js`，测试启动器清理工作区环境覆盖并禁止外部网络。前端执行 `node --test test/*.test.js` 和 `npm run build`。测试涉及真实 HTTP、独立 SQLite 重开、假供应商、本地文件和子进程，不以构建成功替代交互验收。

浏览器实际检查 1280×720、1440×900、1920×1080 三个桌面视口，并补充 390×844 窄屏。覆盖素材库、图片/视频工具、工具目录、反推入口、AI 配置弹窗、首页、账户、资源编辑和画布；检查滚动、最后操作项、固定区域、输入、筛选、返回和刷新。

共享工具页的普通分析、流式分析和剧本创作也完成三个桌面视口及窄屏检查。已停止本次隔离服务，关闭临时验收标签页并恢复视口。

画布多参考请求包含两个资产；首尾帧请求分别使用 `first_frame`、`last_frame`。浏览器链路在隔离配置的 token 预授权上限校验处停止，未进入供应商。这证明真实请求合约，不作为真实生成成功的证据。生成、结算及重启闭环由本地假供应商的项目 HTTP 测试覆盖。

## 验收环境偏差

一个子代理曾在北京时间 10:34–10:39 启动工作区本地后端，使用工作区 SQLite，而非指定隔离数据库。发现后已停止。启动触发自动迁移；核对还发现登录时间更新和一条运营报表快照写入。

只读核对未发现该时段生成、结算、对账、归档或后处理任务的时间戳变化，已有日志也未见供应商请求证据。但启动会执行后台恢复，现有证据不能证明绝无外部请求。未回滚这些本地数据库写入。之后验收使用独立临时数据库、存储、配置及仅允许 loopback 的网络保护，没有访问线上环境。
