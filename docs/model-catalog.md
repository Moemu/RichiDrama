# 模型目录

AI 配置默认打开模型目录。管理员可以从同一个模型条目查看连接、配置价格和上下架。

## 使用流程

1. 在供应商连接中填写接入信息，或为模型选择已有连接。
2. 新模型保存为待上架。模型 ID 和显示名称由管理员维护。
3. 在模型详情中选择已发布价目，填写计价项，保存调价草稿。
4. 审核草稿并发布，再上架模型。进行中任务继续使用预授权价格快照。
5. 下架前更换连接默认模型和业务场景中的显式模型。下架不删除配置、历史价格或任务。

目录中的预设选项来自数据库。供应商地址和接口协议仍保留接入预设。
火山价格同步入口复用已有读取、人工审核和发布流程。模型列表通过“获取模型”按需读取，不自动上架或下架。
同名模型按服务类型和模型 ID 管理，不增加渠道区分规则。

## 兼容边界

- 新表 `ai_model_catalog` 只存目录状态和显示名称。迁移可重复执行，不改写历史配置。
- 现有配置以 `legacy` 状态显示，保留原可用性，未被自动上架、停用或重新定价。
- 从目录新增的模型，以及新版连接表单新增的型号，启用待上架流程。
- 连接表单通过可选字段 `catalog_managed: true` 注册新型号。同名已有型号不会因此改变状态。
- 旧 API 请求不带该字段时保持原语义。历史导入不会自动改变目录状态。
- 目录只限制新请求。已存在的预授权先按幂等键返回；结算仍读取原快照。
- 调价克隆所选价目表，保留其他模型、条件价格、价目所有者和项目组绑定的版本关系。

## 接口及消费者覆盖

| 范围 | 覆盖情况 |
| --- | --- |
| 管理 | 新增管理员专用 `GET/POST /api/v1/admin/model-catalog` 和 `POST /api/v1/admin/model-catalog/price-draft`。不返回连接密钥。 |
| 配置 | 保留原 `ai-configs` 合约；新增可选 `selectable=true`。管理读取保留所有型号，创作读取过滤目录状态及当前用户价目。 |
| 前端 | AI 配置及其内嵌入口、目录筛选、连接预设、一键配置、工具箱模型选项、GenerationSettings。移除工具箱跨页面的永久模型缓存。 |
| 可用模型 | `/models/available`、`/ai-configs` 创作视图、`/video-model-capabilities` 使用目录过滤。项目组权限继续由现有绑定解析。 |
| 新请求 | 文本自动计费、图片路由、角色/场景/道具资源图、视频路由、Omni、TTS 携带实际模型 ID，避免计费键别名绕过状态检查。视频后处理继续使用其现有模型计费键。 |
| 价格及历史 | 复用价目保存和发布、项目组价目绑定、通知、预授权幂等与快照结算。历史列表、媒体持久化及恢复路径不重写。 |
| 默认值 | 下架检查连接默认型号和业务场景 `model_override`；原配置数组保留，防止历史读取丢失。 |

## 自动获取模型

在模型目录点击“获取模型”，选择已保存的目标连接和来源。获取成功后可搜索、分页选择并导入，单次最多导入 200 个型号。

- **OpenAI / OpenAI 兼容**：使用该连接保存的 API Key，读取 Base URL 下的 `GET /models`。根域名补 `/v1/models`，已有版本路径不重复拼接。兼容供应商必须支持此接口；接口返回的型号可能包含其他用途，管理员需确认与目标连接的服务类型一致。
- **火山方舟 · 账户可用模型（默认）**：选择同账号、同区域的 ModelArk 资产库长期 AK/SK 配置，调用 `ListModelActivations`，过滤 `States: ["Available"]`，不请求价格及免费额度。型号、显示名称和状态分别读取 `FoundationModelName`（兼容 `Name`）、`DisplayName` 和 `State`，不拼接版本号。需要 `ark:ListModelActivations` 读取权限；这是账户级查询，不附加端点项目筛选。
- **火山方舟 · 已部署端点**：保留 `ListEndpoints` 来源，导入供应商返回的 `Id`（`ep-…`）。需要 `ark:ListEndpoints` 读取权限，使用配置中的国内区域和可选项目名称。两种火山来源均每次读取一页，后续页点击“继续获取”。
- 账户可用模型和已部署端点是不同列表。前者不要求事先创建端点，但也不等于平台全部未开通模型。仅有推理 API Key、没有管理 AK/SK 时，仍可手动添加型号。
- 获取是管理员的只读元数据操作。仅通过项目 HTTP 路由调用后端原生 HTTP 适配器，不调用推理或计费接口，不创建预授权。业务请求 ID 和供应商请求 ID 记入审计。
- 前端仅传已保存的连接 ID；地址、API Key 和签名密钥留在后端。请求 15 秒超时，禁止自动跟随重定向；异常响应不回显供应商原文或密钥。
- 只追加确认选中的型号。新型号进入待上架；目录中已有型号保留原状态，其他连接中的历史型号仍为 legacy。重复导入跳过已有项。默认模型、原数组项、价格、项目组绑定与历史任务均不重写。

接口均要求运营后台管理员权限：

| 接口 | 行为与消费者 |
| --- | --- |
| `GET /api/v1/admin/model-discovery/connections` | 返回目标连接和可选 ModelArk 凭据的非敏感摘要，包含空型号连接。新增可选 `recommended_source` 供新版弹窗选择账户可用模型；保留原 `source` 字段和值供旧客户端使用。 |
| `POST /api/v1/admin/model-discovery/:id/fetch` | 接收 `source`、可选 `credential_config_id` 与 `page`；返回规范化型号、已有标记、下一页及请求 ID。只读，不同步目录状态。 |
| `POST /api/v1/admin/model-discovery/:id/import` | 接收 `models` ID 数组；事务内追加并复用 `registerNewModels`。厂商锁定模式拒绝导入。返回新增和跳过数量。 |

导入后刷新模型目录、AI 配置和创作选项。已有 `/ai-configs`、`/models/available`、生成路由及价格发布接口保持原合约。重启读取继续使用原配置表和目录表，无新增迁移或后台任务。

新版弹窗显式发送 `source: "volcengine_activations"`。旧客户端的 `volcengine_endpoints` 请求及省略来源的请求保留原查询语义。此前导入的端点、历史模型和价格均不改写。

接口依据：[OpenAI List models](https://developers.openai.com/api/reference/resources/models/methods/list)、[火山官方 ListEndpoints 请求定义](https://github.com/volcengine/volcengine-nodejs-sdk/blob/master/service/ark/src/types/list-endpoints-request.ts)、[火山官方响应型号定义](https://github.com/volcengine/volcengine-nodejs-sdk/blob/master/service/ark/src/types/item-for-list-endpoints-output.ts)。仅参考官方接口定义，未引入供应商 SDK。

## 验证

- 后端测试 386 项通过；前端测试 146 项通过；production build 通过。
- HTTP 集成覆盖权限、目录新增、缺价格拒绝上架、价格草稿及发布确认、新连接型号注册、下架后生成拒绝。
- 重启后目录状态和原配置仍可读取。下架前预授权可重复读取，并使用原价幂等结算。
- 使用独立 SQLite 数据库和无效供应商地址。未执行真实生成或供应商调用。
- 内置浏览器覆盖新增、调价发布、上下架、搜索、刷新，以及 21 行目录的末行操作。
- 实查 `1280×720`、`1440×900`、`1920×1080` 和 `390×844`。修复标签容器截断和窄屏列宽撑开问题；表格横向滚动与内容纵向滚动分开。
- 自动获取测试覆盖管理员权限、已保存密钥、响应去重、错误及重定向拒绝、空列表、原子导入、重复导入、旧状态和默认值保留、火山签名与分页、重启读取。
- 获取弹窗实查以上四档视口，覆盖搜索、跨页选择、已有型号禁选、导入后刷新、火山后续页和失败重试。供应商使用本地 HTTP 模拟及固定响应，未连接真实供应商账号。
- 账户列表回归覆盖 `ListModelActivations` 的请求参数、字段解析、分页、重复导入与重启读取，以及旧端点请求和历史 `ep-…` 记录兼容。该上游接口已由用户使用 curl 验证可返回账户模型列表。

预览部署由 PR 工作流执行；合并及生产发布另行确认。

火山价格同步使用每页 20 个模型，逐页签名读取到 TotalCount。仅调整后续同步请求的批量大小；历史价格与记录不变。不含价格的模型发现仍使用原分页大小。

价格同步遇到上游 InternalServiceTimeout 且重试失败时，从每页 20 降为 10、再降为 5。每次降档丢弃部分结果并从第一页重新读取，保留所有请求 ID 和 45 秒总时限。最低档仍失败或列表不完整时不生成价格候选，不改变已发布价格。

## Seedream 5.0 Pro 分项计费

仅在管理员审核并发布带 `image_pricing_version: seedream-pro-v1` 的新价目后启用。输入图使用 `input_image`，每次请求首张免费；输出图使用 `image`，按单图/图层场景及 2,610,000 像素边界保存四档账户价格。缺项或缺配对价目时拒绝发布与调用，不猜测价格。当前生成 API 仅支持单图，明确拒绝 `layer_decomposition: true`；保存图层价格不代表支持图层生成。

报价根据请求尺寸和参考图预估。后台完成参考图组装后，在供应商请求前按最终数量重新预授权，保留原价格快照。批量请求分别计算免费额度。返回图片先保存本地并读取实际像素，再按冻结价格结算；输入数量固定为实际提交数量。网络未知、服务端异常及本地保存失败保留待对账状态，重启不重复提交或扣费。

历史价目、原预授权、已完成图片、处理中旧任务和历史导入记录不启用此版本规则。表结构升级仅扩展计量单位，保留既有行、索引、触发器和自增序列，重复启动不改写数据。未发布新规则的模型保留原尺寸处理和计费语义。

影响面检查覆盖图片路由、角色/场景/道具生成、批量报价、任务失败释放、价目发布与账本展示。共享 HTTP 返回头为新增字段；Omni、视频、素材导入与合成继续沿用已有路径。新图片完成结果使用本地持久化路径，刷新及重启读取不依赖供应商签名 URL。

新增 HTTP 集成测试覆盖像素边界、首张免费、最终参考图、冻结价格、余额不足回滚、本地图片与请求 ID、异常待对账、重复提交拒绝和历史数据库重启。全部后端测试通过，前端 146 项通过，production build 通过。内置浏览器检查三个桌面基线和 390×844 窄屏，并验证隔离环境的审核、发布、通知和末项滚动。发布弹窗限制在视口内，正文独立滚动，底部操作始终可达。所有供应商响应来自本地模拟，无真实生成费用。

## 共享供应商连接与业务默认模型

新增供应商连接单独保存地址和凭据。导入模型按文本、图片、视频和语音分组；未知型号必须显式选择能力。角色、场景、道具和分镜可共用同一图片绑定。模型目录继续负责定价和上下架，业务场景负责各用途默认模型。

旧配置不会自动转换。管理员主动转换时保留配置 ID、默认值、协议、端点和原始型号数组；新请求排除已知能力不符的型号。新导入模型默认待上架，低优先级，不替换旧默认。已完成、处理中及待对账任务、历史价目和历史同步批次不改写。新增业务默认值仅在保存 `capability-default-v1` 标记后作用于新请求；恢复任务不应用此默认覆盖。项目组权限仍由原绑定控制。

新增 `/api/v1/admin/provider-connections` 的列表、新建、修改及显式转换接口。发现接口可使用 `provider-{id}`，旧数字配置 ID 继续支持。`GET /ai-configs?platform=true` 仅管理员可用，原列表语义不变。共享绑定禁止独立修改能力、供应商、地址或凭据。迁移仅添加共享表、可空关联列和场景版本列，可重复执行。

价格同步的去重依据增加本地能力映射快照。即使供应商价格未变，重新导入到正确能力后也会生成新候选；旧批次仍可读取。未找到同能力连接与供应商价格缺项分别报告，不自动发布。

影响面检索覆盖前端 AI API、连接与发现弹窗、模型目录、场景默认、创作选项，以及后端配置读取、鉴权和项目组绑定、文本/图片/视频/TTS 调用、图片资源、Omni 取消、重启轮询、模型目录和价格同步。媒体存储、素材导入、合成、旧账本和登录会话保持原路径。

隔离 HTTP 测试覆盖混合型号分类、未知能力原子拒绝、重复导入、共享凭据更新、项目组隔离、场景默认、手动模型优先、历史配置及价格重启读取、修正映射后同步去重失效。角色和道具无显式模型请求使用项目 API、模拟供应商及真实本地结算流程验证。后端 393 项和前端 146 项通过，production build 通过。内置浏览器覆盖连接转换/导入/编辑、价格映射、默认模型保存、刷新和末项操作；检查三个桌面基线与 390×844 窄屏。旧场景弹窗已改为视口内滚动。未调用真实供应商或修改生产数据。

## 将多条旧配置关联到同一连接

同 Key、同 Base URL 的火山文本、视频、资源图片和分镜图片可保留为四条绑定，共享一份连接凭据。先把其中一条转换为共享连接，再点击连接卡片上的“关联现有配置”，选择剩余配置并提交。弹窗显示每条配置的兼容性与不能关联的原因；Key 只在后端比较，不返回浏览器。

新增管理员接口 `GET /api/v1/admin/provider-connections/:id/candidates` 和 `POST /api/v1/admin/provider-connections/:id/attach`（`config_ids` 数组）。提交在同一事务内重新检查全部所选配置；任一不兼容则全部拒绝。仅允许未删除的平台通用配置，排除项目组独立配置、专用服务和其他共享连接的绑定。要求同供应商族、同规范化地址、非空且相同的 Key，以及正确的默认模型能力。火山 `volcengine`、`volces`、`volc` 视为同族，但保留每条绑定原来的 provider 值、协议和端点。相同目标的重复请求不会重复迁移或记录审计。

仅管理员明确选中的旧配置写入共享关联、移除重复 Key 并更新时间。原配置 ID、名称、服务类型、原始模型数组、默认值、优先级、计费键、设置、启用状态和项目组绑定不改写。两条图片配置不删除、不合并；其他历史记录不自动关联。读取共享凭据继续复用配置服务，未新增迁移、后台任务或供应商调用。已有生成、恢复和价格同步消费者保持原入口。

影响面复核覆盖连接 API、权限与厂商锁定、配置列表/详情/编辑、共享凭据读取、文本/图片/视频/TTS 与 Omni 调用、模型发现/目录、场景默认和价格同步。HTTP 验证覆盖四配置关联、兼容性失败原子回滚、重复提交、列表刷新、Key 更新、项目组隔离、重启读取及历史任务/价目/预授权保存和结算。内置浏览器验证多选、禁选原因、成功刷新，以及三个桌面基线和 390×844 的滚动与按钮可达性。全部使用隔离数据库和无效供应商地址。
