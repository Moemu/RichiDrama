# FreeCreate 全能创作页重构

## 目标
重做 FreeCreate.vue 的布局与交互，让视频成为视觉中心，任务历史用视频缩略图呈现，SD2 认证全自动无感。

## 涉及文件
- `frontweb/src/views/FreeCreate.vue`（唯一改动文件，纯 UI/交互重构，不动 API）

## 布局重构（三栏：舞台居中占绝大多数）

```
┌──────────────────────────────────────────────────┐
│ 顶栏：返回  全能视频                    打开素材库 │
├───────┬────────────────────────────┬─────────────┤
│素材池 │                            │ 创作控制     │
│(窄,可 │     视频渲染舞台            │ (窄,可折叠) │
│ 折叠) │   （占绝大部分宽度/高度）    │ 提示词      │
│       │     大播放器/渲染动画        │ 参数        │
│ 缩略图│                            │ [开始渲染]  │
│ 列表  ├────────────────────────────┤             │
│       │  近期渲染：视频缩略图网格    │             │
└───────┴────────────────────────────┴─────────────┘
```

CSS Grid 调整（当前 `grid-template-columns: minmax(190px,.56fr) minmax(620px,2.5fr) minmax(285px,.92fr)`）：
- 改为 `minmax(180px, 0.8fr) minmax(1fr, 3.2fr) minmax(260px, 0.9fr)`，让中栏占比从 ~62% 提升到 ~72%
- 素材池和控制面板均可折叠（点击标题折叠成窄条），折叠后舞台进一步占满
- 舞台 `min-height` 从 470px 提升到 `minmax(520px, 72vh)`，视觉占据绝大部分

## 任务历史改为视频缩略图网格

当前 `history-strip` 是横向滚动文字卡片（`<b>渲染中</b><small>{{ prompt }}</small>`）。改为：

```html
<div class="history-grid">
  <article v-for="job in jobs" class="history-card" @click="focusJob(job)">
    <!-- 视频缩略图为主（复用现有 job.videoUrl） -->
    <video v-if="job.videoUrl" :src="job.videoUrl" muted preload="metadata" class="history-thumb" />
    <div v-else class="history-placeholder">
      <el-icon v-if="job.status==='processing'" class="is-loading"><Loading /></el-icon>
      <span v-else>!</span>
    </div>
    <!-- 状态角标 -->
    <span class="status-badge" :class="job.status">{{ jobState(job) }}</span>
    <!-- 重试按钮（仅失败时） -->
    <el-button v-if="job.status==='failed'||job.status==='retryable'" ...>重试</el-button>
  </article>
</div>
```

- 响应式网格：`grid-template-columns: repeat(auto-fill, minmax(150px, 1fr))`
- 缩略图 `object-fit: cover`，hover 时高亮边框，点击在主舞台播放
- 失败任务显示红色角标 + 重试按钮，processing 显示加载动画
- 点击任一缩略图 → 该任务视频在主舞台 `render-canvas` 播放（现有 `activeJob` 逻辑已支持，`focusJob` 已存在）

## SD2 认证全自动（无感）

当前逻辑已有"提交时认证"（`create()` 里对 `usage==='identity'` 的素材自动 certify），但：
1. 用户不知道要选 `identity` 用法
2. 认证过程没明确反馈

改进：
- **提交时自动识别真人图片**：`create()` 时对所有 `type==='image'` 且 `sd2Status!=='active'` 的素材**自动尝试认证**（不要求用户手动选 identity 用法），认证失败的降级为普通参考继续提交
- **认证进度可视化**：主舞台在渲染动画期间显示"正在认证 N 个素材…"→"已提交至 {model}"
- 去掉素材卡上需要用户理解的 SD2 状态标签的视觉权重（保留但弱化为小圆点：绿=已认证、灰=未认证），不让用户觉得"必须先认证"

## 舞台渲染动画保留并增强

现有 `render-canvas` 的轨道动画（`render-orbit` + `render-core` 脉冲）效果好，保留。增强：
- 渲染中时显示当前阶段文案（"认证素材中…" / "提交至火山…" / "生成中… 第 N 轮查询"）
- 失败时舞台显示错误摘要 + 重试按钮（而不是只在文字里）
- 空状态（无任务）显示引导："选择素材 → 输入提示词 → 开始渲染"

## 交互精简

- 控制面板默认展示提示词 + 关键参数（比例/时长），音频等高级选项折叠
- 素材池点击即选中（保持现有 `toggle`），选中态更明显
- 提示词编辑器（OmniAssetPromptEditor）保留，但高度收紧

## 不改动
- API（omniVideoAPI）不变
- 后端接口不变
- OmniAssetPromptEditor 组件不变
- 认证 API 调用逻辑不变（certifyAsset/refreshAssetCertification）
