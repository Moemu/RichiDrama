## 实施计划

### 第一部分:新增豆包 TTS 协议(改 `ttsService.js`)

**1. 新增 `synthesizeWithDoubao(text, opts)` 函数**(参照你给的 Go 示例):
- URL:`{base_url}{endpoint}`,其中 `endpoint` 从 settings 读,缺省 `/api/v1/tts`(你示例的 `tts_middle_layer/tts` 作为可选项,通过 settings.endpoint 配置)
- 认证头:`Authorization: Bearer;{token}` —— 注意是分号不是空格(豆包特有格式)
- 请求体:
  ```js
  {
    app: { appid, token, cluster },        // 从 settings 读
    user: { uid: 'LocalMiniDrama' },
    audio: { voice_type, encoding:'mp3', speed, volume, pitch },  // voice_type 从 settings 读(默认 BV001)
    request: { reqid: uuid, text, text_type:'plain', operation:'query' }
  }
  ```
- 返回判断:`code === 3000` 为成功,`data` 是 base64 音频,解码成 Buffer 返回
- token 用配置里的 `api_key`(即 `ea4416a6…`);appid/cluster/voice_type 从 `settings` JSON 读

**2. 在 `synthesize()` 主函数(:129)接入新分支**:
```js
} else if (provider === 'doubao' || provider === '豆包语音' || provider === 'volcengine_tts') {
  audioBuffer = await synthesizeWithDoubao(text, {
    apiKey: ttsConfig.api_key,
    baseUrl: ttsConfig.base_url,
    settings: ttsSettings,   // { appid, cluster, voice_type, speed, ... }
  });
}
```
- 注意判断顺序:豆包的 `base_url` 有值,要放在 minimax 之后、`else if (openai || base_url)` **之前**,否则会被 OpenAI 分支拦截(这正是当前 404 的原因)。

**3. 配置读取**:appid/cluster/voice_type 从 `ai_service_configs.settings`(JSON)读取。当前 settings 为 null,所以:
- 代码写好后,直接调接口会报"缺少 appid/cluster"的清晰错误(而不是 404)
- 你拿到参数后,通过 SQL 或 API 写入 settings 即可生效,**无需改代码**
